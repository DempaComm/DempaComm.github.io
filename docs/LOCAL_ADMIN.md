# ローカル管理画面

TeX、BibTeX、PDFの編集はVS Codeで行い、変更の検査、LaTeXML HTMLの試験生成、
公開準備、総合検査だけをブラウザで行うローカル専用の画面である。公開サイトの一部ではなく、
外部から接続できない `127.0.0.1` だけで起動する。

リポジトリのルートで次を実行する。

```sh
python3 scripts/paper_tool.py local-admin
```

表示された `http://127.0.0.1:8765/` をブラウザで開く。VS Codeでは「ターミナル」→
「タスクの実行」から「数識電収: ローカル管理画面を起動」を選んでもよい。停止は実行中の
ターミナルで `Ctrl+C` を押す。

## 操作の流れ

1. VS Codeで原稿を編集して保存する。必要ならローカルでPDFを確認する。
2. 管理画面で記事を開き、「変更を検査」を実行する。PDF全ページと表示された個人情報
   検査報告を人が確認する。
3. 修正理由を入力し、確認欄をチェックして「承認して全体検査」を実行する。
4. HTML版が必要な記事では、未承認変更がない状態で「HTML試験版を生成」を押す。生成HTMLと
   PDFを比較した後だけ「HTML版を公開登録」を実行する。
5. HTML公開など意図した公開差分を確認した場合だけ、一覧の「公開基準を更新」を使う。
6. コミットとpushは引き続きVS CodeまたはGitの通常操作で行う。

## 安全上の境界

- 管理画面はTeX本文を編集しない。編集はVS Codeだけで行う。
- `finish-change` と同じ個人情報確認・公開差分承認を要求する。
- 新しいBibTeX、図版など、`paper.json` にまだ登録されていない公開ファイルの追加は
  初期版の画面では扱わない。通常の移行手順で追加する。
- Gitのcommitとpush、外部公開、localhost以外への待受は画面から実行できない。
