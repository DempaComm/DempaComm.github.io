# SATySFi変換試作

LaTeXからSATySFiへの最小変換器を
[`packages/dempa-satysfi-converter/`](../packages/dempa-satysfi-converter/README.md) に実装した。
Pandoc JSON ASTを中間表現として検査し、未知の構造や数式命令を推測せず安全停止する。

## 2026-08-01の確認結果

ローカルのSATySFi `v0.0.11-22-gc2cbc48`、opam `2.5.2`、Pandoc `3.10.1` を使用した。
人工例は回帰テストで変換、決定性、安全停止、警告なしPDF生成を確認した。

実原稿「素数の無限性」は元TeXを変更せず隔離領域で試験し、次を確認した。

- A4、1ページのPDFを生成できる。
- 定義・命題・定理4件、証明2件を保持する。
- ラベル2件と参照2件をSATySFiの相互参照として解決する。
- インライン数式53件を変換する。
- SATySFiコンパイルのエラー、警告、行あふれがない。
- 証明末尾は収録フォントにない白四角を避け、`（証明終）` とする。

実原稿、Pandoc AST、SATySFiソース、PDF、ログは公開テストへ収録していない。試験成功だけで
公開候補とはせず、変換報告も `manual_review_required: true`、`publishable: false` を維持する。

## 2026-09-12の確認結果

段落と番号付き列挙からなる定理、レベル1見出し、複数段落と任意題名を持つ証明、追加の数式命令を
人工例から実装し、「The Horrible lemma」と「ストーン-ワイエルストラスの定理」を隔離変換した。
後者はA4・4ページを生成し、元PDF全3ページと本文、見出し、定理、列挙、数式を比較した。

続いてBibTeX原稿「論文メモ --- 領域不変性定理 ---」で次を確認した。

- 属性なしSpan、通常の引用、`\nocite{*}`、BibTeX文献一覧、HTTP(S)リンクを保持する。
- 引用番号 `[2]`, `[1]` と文献一覧2件の順序が一致する。
- URLとDOIを生成PDFのリンク注釈として保持する。
- SATySFiコンパイルエラーはなく、A4・1ページを生成する。
- 独自BST `myplaindoidoi` の書式は再現せず、変換報告へ明示警告を残す。
- 元PDF全1ページと比較し、本文、URL、引用、文献の内容対応を確認する。

元PDFの日付はPandoc ASTで空になるため再現対象に含めていない。引用前置・後置や特殊モード、
未解決文献キー、装飾属性つきSpanは成功扱いにしない。

さらに画像原稿「コンパクト集合の共通部分」で次を確認した。

- 同じディレクトリのJPEG画像をバイト単位で隔離出力へコピーする。
- 図1、画像、数式を含むキャプションを保持する。
- `\mathfrak`、`\omega`、`\cup`、`\cap` をSATySFi数式として保持する。
- SATySFiコンパイルエラーはなく、A4・2ページを生成する。
- 元PDF全1ページと比較し、本文、数式、画像、図番号、キャプションの内容対応を確認する。
- 元の `scale=0.21` とfloat配置 `h` はPandoc ASTから復元せず、既定幅への正規化と配置差を警告する。

画像欠落、安全でない相対パス、シンボリックリンク、複数画像または装飾付き図版は成功扱いにしない。

単純な表については、実原稿をコピーせず `examples/table/input.tex` の人工例で次を確認した。

- 2列3行のセル本文とインライン数式を保持する。
- 表1とキャプションを保持し、A4・1ページを警告1件でコンパイルする。
- 列配置は中央揃えへ正規化し、元指定との差を警告する。
- セル結合、列幅指定、複数区画、複数段落セルは安全停止する。

収録原稿を検索した範囲では通常の `tabular` 表は見つからず、数式中の `array` だけだったため、実原稿
による成功例は作っていない。

2026-09-19に、丸括弧で囲まれた2×2の数式 `array` を限定対応した。

- `l`・`c`・`r` の列指定だけを許し、SATySFiの型付き行列命令へ4成分を渡す。
- 人工例 `examples/matrix/input.tex` を警告なしでA4・1ページへ変換する。
- 括弧、2行2列、負号を含む成分を生成PDFで確認する。
- 罫線、空セル、別サイズ、場合分け、丸括弧なしは安全停止する。
- 「Clarkson不等式」では2×2行列1件に変換規則が適用されたが、引用符と未対応数式命令が残るため、
  文書全体は出力せず安全停止する。

続いて、単一・二重引用符とSATySFi標準に直接対応する数式命令を人工例から追加した。`\colon`、
`\ell`、`\exp`、BibTeX由来の `\sp{...}` は明示規則で変換する。「Clarkson不等式」では引用符1件、
行列1件、`\exp` 5件などに規則が適用され、停止理由は `\bar` と複合した縦線・ノルムの3種類まで
減った。

さらに、波括弧で閉じた `\bar{...}`、明示的な `\|...\|`、`\left|...\right|`、閉じ側の境界が
確定する `|...|` を型付き上線、ノルム、絶対値へ限定変換した。単独または曖昧な縦線は安全停止する。
「Clarkson不等式」はエラーなしでA4・11ページを生成し、SATySFiログに警告がないことと全11ページに
欠落・重なり・切れた文字がないことを確認した。独自BST非再現の警告1件は変換報告へ残している。

## 次の範囲

2×2以外または罫線付きの数式 `array`、場合分け、複雑な表、複数画像・装飾付き図版、下位レベル
見出しは未対応である。それぞれ人工的な最小入力と安全停止テストを先に追加してから対応する。
独自BSTの書式再現は別課題とし、現在は差異を警告する。公開連携は変換器が安定し、
複数原稿の内容比較方法が定まるまで行わない。
