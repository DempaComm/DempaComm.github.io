# 児玉・永見『位相空間論』の参考文献案内

2026-10-11付の新しい記事として登録した。[記事紹介](https://dempacomm.github.io/papers/2026-10-11-01/)から「文献案内を読む」で[文献案内](https://dempacomm.github.io/kodama-nagami/)を開ける。新着・記事一覧・年別一覧・RSSにも載る。電波通信の著者が人力で作成した旧リストを引き継いだことと、AIによる整理・拡充を文献案内の冒頭で説明する。

## 開く

リポジトリのルートで次を実行する。

```sh
python3 scripts/paper_tool.py stage _site
python3 -m http.server 8767 --bind 127.0.0.1 --directory _site
```

[紹介ページ](http://127.0.0.1:8767/kodama-nagami/)から、文献一覧、本文対応、あとがき、推定と付記へ進める。
トップページにも入口を追加した。サーバーを終了するときは起動したターミナルでCtrl+Cを押す。

## 取り込んだ記録と範囲

利用者が指定した「児玉永見位相空間論の参考文献を作ることはできるか?はてなブログ電波通信に少しリストがあるよ」チャットから、最新の正本と件数・留保の情報を受け取った。

- 書誌は278文献である。分冊・翻訳別を含むBibTeXは282項目である。
- 原文による個別対応は351件である。定義・問題文・限定された主張の対応も含む。
- 推定・適用範囲の付記は19項目である。追跡18項目とFrolíkの刊年問題を扱う。
- あとがき全10項目の指定は20文献に対応する。
- 1974年より後の31文献を、後年の照合・歴史的補助資料として表示する。

書誌状態は通読・証明検証状態に読み替えない。主題による節候補と原典との個別対応を区別し、間接採用を直接照合へ格上げしない。節候補は`section_candidates.json`の`records`配下だけを取り込んだ。

頁体系についても調査チャットへ再確認した。本書の`book.page`・`book_page`・`page_start`・あとがきの`page`は1974年原著の印刷頁である。問題47.25は原著318頁にある。`fox-morales1976-50-22`の`book.page`は印刷頁範囲`340–341`である。原文献の`paper.page`は文献側の印刷頁である。

Ishii演習10.Jの単一典拠は未同定として関連文献を併記する。Worrellは題名を後続引用から採用した未刊行原稿で、刊年・誌名・巻頁を作らない。Frolík積論文の1960/1961年の相違を残す。問題47.25は訂正済みの「可算密度」「斉次」を使う。本書全出典の網羅、著者実使用、絶対的初出、独立証明監査の完了は認定しない。

## データを保つ

公開用入力は`content/kodama-nagami/bibliography.json`と`kodama-nagami.bib`である。元JSONとBibTeXは`_experiments/kodama-nagami/source-snapshot/`へバイト一致で保存し、`content/kodama-nagami/source-manifest.json`にSHA-256・取得元チャット・加工範囲を記録した。

公開用コピーではローカル資料へのURLを除外し、付記内の保存パスを表示用の文言へ置き換えた。取得・加工方法は本文・詳細欄・JSON・BibTeXへ載せない。元の書誌識別子、印刷頁、比較・根拠・閲読範囲・留保を保つ。公開用のBibTeXは282項目を保ち、非公開のローカルURLを除いた。原資料に含まれる書誌上の留保・Biber警告は残る。

「本書の主張の要約」は、文献案内のために独自の短文で説明する。351対応が扱う335箇所の要約を`content/kodama-nagami/book-summaries.json`に保つ。各要約は一〜二文、現状では最長64文字で、問題は何を問うかを述べ、部分的な対応や主要な条件を残す。公開JSONの`book.summary`にも同じ要約を使い、原文に近い`book.statement`は出力しない。同じ記述が原文献の欄にも現れる場合は、その部分を要約に置き換える。空間の規約も独自の短文で説明する。厳密な定式化は原著の頁・番号を参照する。

元記録の各記述のSHA-256を要約と結び付け、入力が変わったときは自動再利用せず、要約の点検を要求する。再取り込み時は書誌の変更に加えて、要約の対応先と仮定・結論の趣旨を点検する。引用の目的と正当な範囲などの要件は[文化庁の案内](https://www.bunka.go.jp/seisaku/bunka_gyosei/kibankyoka/faq/index.html)を参照できる。この要約編集とサイト検査は、法的な適否の判定とは区別する。

紹介本文で取り上げたMorita 1970、Arhangelskij 1971、Nagami 1973の保存PDFは`_experiments/kodama-nagami/sources/`へコピーした。確認範囲は同フォルダの`manifest.json`に記録した。他の保存資料は元の調査プロジェクトに残っている。登録208文献・207PDFにはプレビュー等も含むため、同数の原論文全文取得とは扱わない。

再取り込みには、調査チャットの正本とローカルの取り込みスクリプトが必要である。これらは公開リポジトリには含めない。正本を確認した上で次を実行する。日付は実際の取得日にする。

```sh
python3 _experiments/kodama-nagami/import_kodama_nagami.py /path/to/source-project --date YYYY-MM-DD
python3 scripts/paper_tool.py catalog
python3 scripts/paper_tool.py check-all
```

## 実装と確認

ページ固有の生成・検索・スタイルは`dempa_site/features/kodama_nagami.py`・`.js`・`.css`にまとめた。登録済み機能として隔離生成する。トップからリンクするため必須機能として扱い、生成失敗時にリンク切れの公開物を作らない。

JSONとBibTeX、5ページの生成、原著印刷頁範囲、訂正反映、推定表の参照先、ローカルパスの除外を検査する。既存の機能隔離テストで無効化・失敗・パス衝突・以前の出力保持も確認する。`python3 scripts/paper_tool.py check-all`でサイト全体を検査する。

2026-10-11の最終確認では、`check-all`の5項目がすべて通った。ブラウザーで文献検索・絞り込み・対応への移動・条件の再読込、あとがきの巻別表示を確認し、パソコンと390px幅のスマートフォン表示を確認した。公開用BibTeXのBiber検査はエラー0件で、元資料から引き継いだ警告81件を検査記録に残した。原資料8ファイルのSHA-256一致も確認した。確認記録は`_experiments/kodama-nagami/validation.json`に保存する。

サイト生成で作るHTML・原資料・保存論文はGitへ追加しない。新記事の入口である`papers/2026-10-11-01/guide.html`は保護原稿として登録し、Gitで管理する。`_experiments/`は公開対象外である。公開用出力は書誌・調査要約・付記・外部原典リンク・BibTeXであり、本書や保存PDFの全文を配布しない。
