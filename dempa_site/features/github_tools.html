01 / SKILLS

日本語の数学文書を書く・読む

skillsは、AIに作業の進め方や参照資料を伝える指示と資料のセットです。japanese-math-skillsには、日本語の論文・解説・講義ノートに使う2本を収録しています。

執筆・改稿・推敲

write-japanese-math

対象読者と編集範囲を確かめ、定義・定理・証明のつながりを保ちながら日本語の文章を整えます。英語原稿の和訳を伴う改稿にも使えます。

依頼の例

$write-japanese-math を使って、この定理と証明を学部3年向けの日本語の解説にしてください。
執筆スキルの内容を読む ↗

独立した読者によるレビュー

read-japanese-math

版を固定した原稿を、執筆時の会話や作業履歴を渡さずに別の読者へ委任します。読者がつまずく箇所、説明の不足、前後のつながりを、場所を示して報告します。

依頼の例

別エージェントに $read-japanese-math を使わせ、この原稿を学部3年の読者として editorial 方式でレビューしてください。
レビュー用スキルの内容を読む ↗

レビューには、順に読む continuous、全体を読む editorial、変更箇所を読む delta の3方式があります。独立レビューは明示的に依頼したときに行い、原稿を書き換えずに読解上の指摘を返します。証明の正しさの認定は、これらのskillsの役割に含まれません。

使い始めるには

  1. リリースページのAssetsから配布用ZIPをダウンロードし、展開します。
  2. skills/write-japanese-mathとskills/read-japanese-mathを、利用するAI環境のスキル探索フォルダへ一緒にコピーします。レビュー用スキルが執筆基準を参照するため、2フォルダは隣り合わせに置きます。
  3. 対象原稿と読者、修正する範囲を添えて、上の例のようにスキル名を指定します。

既存の同名スキルがある場合は退避してから更新してください。導入の詳細はREADMEの導入手順を参照できます。

02 / CORPUS

数学の表現を、前後の文脈とともに探す

日本語数学文書用のskillsには、数識電収の公開TeXを出典とするコーパスを同梱しています。定義を導入する、対象を選ぶ、独立性を確かめる、結論へ進む、といった文章や論証の役割から用例を探せます。

表現の使い方を読む

前後の原文と出典、定理環境を一緒に読み、用法を確認した例と自動抽出した候補を見分けられます。登録された別表記も検索できます。

証明の運びを読む

証明のまとまりを、設定・目標・論証・結論に対応する原文と編集注からたどります。各例を使える場面や必要な前提も確認できます。

手元のブラウザで検索する

Python 3.10以上を用意し、展開したパッケージのフォルダで次を実行します。追加のPythonパッケージやTeX環境は不要です。

python3 viewer/serve.py

起動後、ブラウザのアドレス欄にhttp://127.0.0.1:8769/を入力すると検索画面が開きます。コマンドから用例を探すこともできます。

python3 skills/write-japanese-math/scripts/corpus.py '1の分割' --limit 3

用例は、対象原稿に合う表現を選ぶための資料です。頻度の高い表現を一律の規則にしたり、採録された証明を条件の違う問題へそのまま移したりせず、前提と文脈を確かめて使います。

04 / EXPERIMENTS

変換の試作ツール

ここからは実験段階のプロジェクトです。対応する入力と現在の制限を各READMEで確認してから、小さな例で試せます。

Typstへの変換補助 · アルファ版

dempa-typst-converter

Tylaxが生成したTypstソースを補正し、日本語の定理・証明を共通スタイルで組版するためのツールです。元のTeXと生の変換結果を保ち、補正内容や停止理由を報告します。

未対応の命令や未解決の参照などは停止対象です。生成物は元PDFと見比べて確認します。

対応範囲と試し方 ↗

SATySFiへの変換 · アルファ版

dempa-satysfi-converter

Pandocの中間表現を経由してLaTeXをSATySFiへ変換する試作です。元原稿を一時領域へコピーし、変換ソース、報告、ログ、PDFを分けて保存します。

本文・基本的な数式や定理・参照が初期範囲です。引用・文献・図版・表などは未対応で、生成物には目視確認が必要です。
