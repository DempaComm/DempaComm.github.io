# 要件

## 必須要件

1. 元LaTeX原稿と付属ファイルを変更しない。
2. 変換時は原稿を一時領域へコピーし、出力は隔離領域だけに作る。
3. 生の中間表現、SATySFi出力、コンパイルログ、変換報告を分けて保存する。
4. 未対応ノード、未知のLaTeX命令、失われたラベル・引用・図版を成功扱いにしない。
5. 変換規則ごとに識別子、説明、適用回数または対象位置を報告する。
6. 入力と既存出力を上書きしない。
7. `manual_review_required: true`、`publishable: false` を既定とする。
8. 元PDFと生成PDFの全ページ比較を公開前に必須とする。

## 対応範囲の評価

- 日本語本文と句読点
- インライン数式と別行立て数式
- 定義、命題、定理、補題、系、例、証明
- 共通定理カウンターと相互参照
- 箇条書き、表、脚注
- BibTeX、引用、参考文献
- 画像、TikZ、可換図式
- 独自マクロとパッケージ依存
- タイトル、著者、日付、PDFメタデータ

## テストデータ

テストは新規作成した小さな原稿だけを使う。実在記事の本文、氏名、メール、所属、非公開ログを
コピーしない。実原稿はローカルの隔離試験だけに使い、リポジトリへ含めない。

## 完了条件

- 人工的な単純原稿を変換してSATySFiでPDF生成できる。
- 未対応構造のテストが安全に失敗する。
- 同じ入力から決定的な出力と報告を得られる。
- README、導入、変換、開発、公開手順が実装と一致する。
- 数識電収の通常公開がSATySFi変換の成否に依存しない。
