# 引き継ぎ

## 現在地

2026-08-01にPython製の最小変換器 `0.1.0a0` を実装した。Pandoc JSON ASTを正式な中間表現とし、
SATySFiヘッダを同梱し、Apache-2.0を選択した。人工例の回帰テストと「素数の無限性」を使う
ローカル隔離試験でPDF生成まで確認済みである。実原稿と生成物はパッケージへ収録していない。

確認した環境はSATySFi `v0.0.11-22-gc2cbc48`、opam `2.5.2`、Pandoc `3.10.1` である。

## 次の候補

1. 見出し、複数段落の定理、引用・参考文献、図版の各仕様を個別に決める。
2. 対応範囲ごとに人工例と安全停止テストを先に追加する。
3. 位置情報を変換報告へ加え、手動確認箇所を絞り込む。
4. 複数の代表原稿を隔離試験し、元PDFとの内容比較方法を整備する。

## 維持する境界

- `papers/*` と元原稿を変更しない。
- 実原稿を公開テストや利用例へ追加しない。
- 未知の構造を黙って削除しない。
- 変換結果を自動公開しない。
- Typst変換器へSATySFi固有処理を混在させない。
