# 引き継ぎ

## 現在地

Python製の変換器 `0.1.0a8` を実装している。Pandoc JSON ASTを正式な中間表現とし、SATySFi
ヘッダを同梱し、Apache-2.0を選択した。人工例の回帰・コンパイルテストに加え、「素数の無限性」、
「The Horrible lemma」、「ストーン-ワイエルストラスの定理」、「論文メモ --- 領域不変性定理 ---」
を使うローカル隔離試験でPDF生成まで確認済みである。実原稿と生成物はパッケージへ収録していない。

2026-09-08に、単純な `align`、複数段落の証明、一段落の脚注、和の上下限、添字付き射影記号、
`\Longrightarrow`・`\iff`・`\cdots`・`\max`・`\prec` を追加した。「The Horrible lemma」の
変換報告はエラー・警告とも空で、生成PDF全2ページを目視確認した。元の公開PDFは1ページであり、
版面差によるページ数の一致は完了条件にしていない。

同日に、レベル1の番号付き・番号なし見出し、段落と番号付き列挙からなる定理本文、proof環境の
オプション題名、`\bigcup` の上下限、`\equiv`、`\le`、`\varepsilon`、対になった絶対値・ノルムを
追加した。「ストーン-ワイエルストラスの定理」は元原稿を変更せず隔離変換し、SATySFiのエラー・
警告とも空でPDF全4ページを目視確認した。元の公開PDF全3ページとも比較し、本文、見出し、定理、
列挙、数式の対応を確認した。版面と証明終端の表現は異なり、元PDFの日付はPandoc ASTでは空なので
再現対象に含めていない。曖昧な単独縦線と下位レベル見出しは安全停止する。

2026-09-12に、属性なしSpan、通常の引用、`\nocite{*}` を含むBibTeX文献一覧、HTTP(S)リンクを
追加した。BibTeXは入力TeXと同じディレクトリから一時領域だけへコピーし、Pandoc citeprocで展開
する。引用番号は展開後の文献順と一致させ、未解決キー、特殊な引用形式、装飾属性つきSpanでは安全
停止する。独自BSTはciteprocでは適用できないため、成功扱いの中でも必ず
`BIBLIOGRAPHY_STYLE_NOT_PRESERVED` 警告を残す。

「論文メモ --- 領域不変性定理 ---」は元原稿を変更せず隔離変換し、SATySFiエラーなし、独自BST
非再現警告1件でA4・1ページを生成した。元PDF全1ページと比較して本文、URL、引用順 `[2]`, `[1]`、
文献2件を確認し、生成PDF内のURL注釈2件も検査した。元PDFの日付はPandoc ASTでは空のため再現
対象に含めていない。

同日に、単一のローカル画像とキャプションからなる図版を追加した。JPEG・PNG・PDFだけを入力原稿と
同じディレクトリから隔離出力へコピーし、安全でないパス、欠落画像、シンボリックリンク、複数画像や
装飾属性では停止する。図番号とキャプションは保持するが、Pandoc ASTで失われる元の寸法とfloat配置は
既定値へ正規化し、変換報告へ警告する。「コンパクト集合の共通部分」は元原稿と画像を変更せず、
画像1枚を含むA4・2ページとして警告のみでコンパイルした。元PDF全1ページと比較し、本文、数式、
画像、図番号、キャプションの対応を確認した。

続いて、キャプション付きでセル結合のない単純なPandoc Tableを追加した。図表番号、セル内の本文と
数式を保持し、列配置は中央揃えへ正規化して警告する。セル結合、列幅指定、表頭・表脚、複数本体、
複数段落セルは安全停止する。公開可能な人工例 `examples/table/input.tex` をPDFまで変換し、A4・1ページ
の全体を目視確認した。収録実原稿には通常の `tabular` 表が見つからず、数式中の `array` だけだった
ため、実原稿へは無理に適用していない。

2026-09-19に、丸括弧で囲まれた2×2の数式 `array` をSATySFiの型付き行列命令へ変換した。
列指定は `l`・`c`・`r` だけを許し、罫線、空セル、別サイズ、丸括弧なしでは停止する。人工例
`examples/matrix/input.tex` を警告なしでA4・1ページへ変換し、括弧、4成分、負号を目視確認した。
実原稿「Clarkson不等式」では対象行列1件の変換規則適用まで確認したが、引用符と多数の未対応数式
命令が残るため、文書全体は正しく安全停止している。

同日に、Pandocの単一・二重 `Quoted` を引用符ごと保持した。またSATySFi標準に直接対応する
`\chi`、`\int`、`\lim`、`\mathcal`、`\mathop`、`\mathrm`、`\mu`、`\nu`、`\partial`、
`\subset`、`\sup`、`\theta` を許可し、`\colon`、`\ell`、`\exp`、`\sp{...}` を限定変換した。
続いて、波括弧で閉じた `\bar{...}` を型付き `\dempa-bar` へ変換し、明示的な `\|...\|` と
`\left|...\right|`、閉じ側の境界を確認できる `|...|` をそれぞれノルムと絶対値へ変換した。
単独の `a|b` と `a|b|c` は引き続き停止する。「Clarkson不等式」はエラーなしでA4・11ページを
生成し、SATySFiログに警告がないことと全ページの表示を確認した。独自BSTを再現しない警告1件は
変換報告に残している。

確認した環境はSATySFi `v0.0.11-22-gc2cbc48`、opam `2.5.2`、Pandoc `3.10.1` である。

## 次の候補

1. 「Clarkson不等式」の元PDFと生成PDFについて、数式・本文・文献の内容対応を確認する。
2. 独自BSTをSATySFi側でどこまで再現するかは、citeproc出力との差が問題になる原稿で個別に決める。
3. 対応範囲ごとに人工例と安全停止テストを先に追加する。
4. 位置情報を変換報告へ加え、手動確認箇所を絞り込む。
5. 元PDFと生成PDFの内容比較を半自動化し、ページ数に依存しない確認項目を整備する。

## 維持する境界

- `papers/*` と元原稿を変更しない。
- 実原稿を公開テストや利用例へ追加しない。
- 未知の構造を黙って削除しない。
- 変換結果を自動公開しない。
- Typst変換器へSATySFi固有処理を混在させない。
