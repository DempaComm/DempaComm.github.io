# 構成案

実装前の推奨案であり、調査結果に基づいて別スレッドで確定する。

```text
LaTeX原稿
  ↓ Pandoc等
構造化中間表現（候補: Pandoc JSON AST）
  ↓ dempa-satysfi-converter
main.saty + 変換報告
  ↓ 電波通信用SATySFiスタイル
SATySFi PDF
```

## 責務

- `src/`: 中間表現の検査とSATySFiコード生成。見た目の詳細を持たない。
- `styles/`: ページ、書体、定理、証明、参考文献などの組版。
- `tests/`: ASTノード単位の変換、失敗条件、決定性を検査。
- `examples/`: 利用者が実行できる新規作成の最小例。

## 最初に比較する案

1. Pandoc JSON ASTからSATySFiを生成する小型変換器。
2. LaTeXML XMLを中間表現として利用する案。
3. LaTeXパーサーを直接利用する案。

正規表現だけで全文変換する案は、環境の入れ子、独自マクロ、数式、参照を安全に扱えないため
第一候補にしない。既存ライブラリを採用する場合は、ライセンス、保守状況、日本語と数式の
保持を確認する。

## 公開境界

変換器リポジトリは生成・検査までを担当し、数識電収へのファイル登録、公開承認、Git操作を
行わない。公開側との接続は変換器が安定してから別工程で設計する。
