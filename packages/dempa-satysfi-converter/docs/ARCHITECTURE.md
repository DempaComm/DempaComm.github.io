# 構成

```text
LaTeX原稿・同じディレクトリのBibTeXと参照画像（読み取り専用）
  ↓ 一時領域へコピーしてPandoc + citeprocを実行
pandoc-ast.json
  ↓ ASTと数式命令を許可リストで検査
main.saty + dempa.satyh + conversion-report.json
  ↓ 任意の --compile
main.pdf + satysfi.log
```

`cli.py` は隔離、同じディレクトリにあるBibTeXの一時コピー、参照画像の検査と出力先へのコピー、
Pandoc・citeproc・SATySFi実行、
成果物と報告の保存を担当する。`converter.py` はPandoc ASTの構造検査、citeprocが展開した文献順と
引用番号の対応、SATySFiコード生成を担当し、`math.py` は数式命令の限定変換を担当する。見た目、
相互参照、HTTP(S)リンク登録、画像表示、単純表のセル組版はパッケージデータの `styles/dempa.satyh`
に閉じ込める。独自BSTは
citeprocへ適用せず、書式差を変換報告の警告として残す。画像は安全なファイル名を持つJPEG・PNG・
PDFに限定し、欠落、ディレクトリ移動、シンボリックリンク、既存出力との衝突では安全停止する。
Pandoc ASTで失われるLaTeXの画像寸法とfloat配置は既定幅へ正規化し、その差を警告する。

表はPandoc Tableのうち、キャプション1段落、既定列幅、一つの表本体、結合なし、各セル1段落の形だけを
受け入れる。セル結合、列幅指定、表頭・表脚・複数本体、セル属性や複数段落は安全停止する。SATySFi
側では当面すべて中央揃えに正規化し、元の列配置との差を警告する。

数式中の `array` は通常のPandoc Math文字列に残るため、丸括弧で囲まれた2×2かつ列指定が
`l`・`c`・`r` のみの場合に限って、4個の型付き数式引数を取る `\dempa-matrix` へ変換する。
罫線、空セル、行列サイズ不一致、場合分け、丸括弧なしの配列を推測して変換しない。

Pandocの `Quoted` は引用種別を検査し、二重引用を `“…”`、単一引用を `‘…’` として内容を再帰的に
変換する。未知の引用種別では停止する。数式命令はSATySFi標準との対応を確認して許可し、TeXの
`\colon`、`\ell`、`\exp`、`\sp{...}` と、波括弧で閉じた `\bar{...}` を明示規則で変換する。
明示的な `\|...\|` はノルムへ変換し、`\left|...\right|` は内側を再帰変換して絶対値へ変換する。
通常の `|...|` は閉じ側が演算子、上付き・下付き、波括弧終端などで確定する場合だけ変換し、単独の
`a|b` や `a|b|c` は停止する。

変換は全体成功か全体失敗のどちらかである。未対応ノード、未対応数式命令、重複ラベル、未解決参照を
検出した場合は報告を残すが `main.saty` を出力しない。コンパイラ警告も変換報告へ記録する。

変換器は生成と検査までを担当し、数識電収への登録、公開承認、Git操作を行わない。サイト本体の
公開成否もこの変換器に依存させない。
