# 独立リポジトリとして公開する手順

このフォルダを独立させる前に、次を確認する。

1. 実原稿、著者情報、メール、非公開ログが含まれていない。
2. `tests/` と `examples/` は新規作成した最小例だけである。
3. `python3 -m unittest discover -s tests -v` が成功する。
4. `examples/simple/main.typ` が現行Typstでコンパイルできる。
5. `README.md` の対応範囲と未対応範囲が実装と一致する。
6. バージョンと `CHANGELOG.md` を更新する。
7. Apache-2.0と第三者由来コードの表示を確認する。
8. 生入力を上書きしないことと、停止時に補正版を作らないことを確認する。

切り出した後は、このフォルダを新しいGitリポジトリのルートにする。最初の公開版は
`0.1.0a0` のプレリリースとし、定理・参照の自動変換が完成するまで安定版を名乗らない。
