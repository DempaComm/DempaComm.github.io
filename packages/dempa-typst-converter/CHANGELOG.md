# Changelog

## 0.3.0a0 - Unreleased

- 既存の `blocking_findings` を維持したまま、入力上の行・列、診断コード、対象トークンを持つ
  `diagnostics` 配列をJSON報告へ追加。
- 未対応LaTeX命令、残存ラベル、未解決参照、対応しない境界マーカーの位置をCLIにも表示。
- Tylaxが固定表示へ変えた `Fact` と `Lemma` を共有番号付き構造へ復元。
- 事実・例環境と、単純な手書き参考文献の表示へ対応。
- 数式中に残る `\displaystyle` 由来の `display` トークンを安全に除去。
- 絶対値内の分数を集合として表示するTylax由来の余分な波括弧を除去。
- 元TeXを読み取り専用の手掛かりとして使い、完全一致する任意題名だけを本文から分離。
- 元TeXを渡さない場合や題名境界が一致しない場合は、推測せず報告または安全停止。
- Typst導入済み環境では、出力前の実コンパイル検査を必須化して偽の成功を防止。
- 「代数学の基本定理2」を隔離変換し、A4・2ページのPDF生成と全ページ紙面を確認。
- 数字だけの定理ラベルと参照、単一行の古い証明記法を安全な境界内で復元。
- 対応するTylaxマーカーを持つLaTeX `comment` 環境の混入内容を除外。
- 数式中に残る `\card` の固定表示をTypst演算子へ変換。
- 元TeXが番号なし表示数式だけを持つ場合はTylaxの全体数式番号を除去し、番号方式が
  混在する場合は安全停止。
- 「順序数の位相的重み」を隔離変換し、A4・1ページのPDF生成と全ページ紙面を確認。

## 0.2.0a0 - Unreleased

- 対応するTylaxマーカーを持つ定義・命題・定理・補題・系を共通スタイルへ変換。
- 明示的な終端記号を持つ証明を `#proof` へ変換。
- 文番号を固定値へせず、ラベル付き番号要素と番号だけの相互参照へ変換。
- 重複ラベル、未解決参照、対応しない環境境界を検出して安全停止。
- 定理構造を使う出力と一緒に `dempa-style.typ` を生成。
- 「素数の無限性」の前回試験出力から、A4・1ページのPDFを自動生成できることを確認。

## 0.1.0a0 - Unreleased

- 独立リポジトリへ切り出せるPythonパッケージ構成を追加。
- Tylax出力に残る `\neq` の保守的な補正を追加。
- 文字列・コメント内のトークンを補正対象外にし、入力・既存出力の上書きを拒否。
- 定理マーカー、ラベル、参照、未知のLaTeX命令を検出して停止する報告を追加。
- A4、日本語、定義・命題・定理の共通番号、証明を扱う `dempa-style.typ` を追加。
- 実原稿を含まない最小例とテストを追加。
