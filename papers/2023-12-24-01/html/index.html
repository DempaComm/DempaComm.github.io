1 本文

1.1 リーマンの関数

リーマンは関数

f⁢(x)=∑n=1∞sin⁡(n2⁢x)n2

について 至る所微分不可能と 言ったらしいが， 結局いくつかの点では微分可能であることが証明されているようだ． リーマンの関数に関する論文は多分以下の通りである． 論文 [19] [13], [8], [27], そして [28] を参照のこと．

1.2 ワイエルストラスの関数

ワイエルストラスの関数は 以下の関数である．

f⁢(x)=∑n=0∞an⁢cos⁡(bn⁢π⁢x).

ここでa∈(0,1) であり， bは奇数である正の整数であり， さらにa⁢b>32⁢π+1 を満たすものである．例えば a=1/2でb=73とすればこの条件を満たす． つまり

f⁢(x)=∑n=0∞cos⁡(73n⁢π⁢x)2n

は連続だが至る所部分不可能な関数である． ワイエルストラスの関数はなんか反例として よく出てくるが，別にワイエルストラスが最初に こういう例を構成したわけではないらしい(1875に論文発表)． 例えば [18] は1830年の論文でウィエルストラスより前らしい (今から数えると約200年前である)． 数学書[7] にはワイエルストラスの原論文と Kiesswetterの原論文 の 英訳が載っている． これ以外にもなんか色々あったような気がする． そういう細かい話は参考文献 [31] と [14] を参照のこと．

論文 [16] ではフーリエ級数みたいなフレーバーでワイエルストラス関数の 微分不可能性を 証明しているようだ． 論文 [9] ではワイエルストラスの関数の条件をちょっと改良したようだ．

数学書 [32] にも証明が載っている．

ワイエルストラス関数のグラフのハウスドルフ次元を計算する研究がある． 例えば [2] や [12] などを参照のこと．

論文 [和5] にも原論文に沿った証明が紹介されている．

1.3 高木関数

今連続関数s:ℝ→ℝを s⁢(x)=infn∈ℤ|x−n|と定義する． つまりs⁢(x)は 点xと集合ℤの距離である． このとき高木関数t:ℝ→ℝ を

t⁢(x)=∑n=0∞s⁢(2n⁢x)2n

と定義する． 高木貞治が構成したというこの 至る所微分不可能な連続関数 は大体以下の論文で 触れられていると思う． 論文[30] は高木の原論文で， 有名な解析概論[和4] の付録で高木関数が紹介されている．

2 Appendix

せっかくだし実数上に連続だが 微分不可能な関数が存在することを証明しよう． 講究録 [和5]や [31]に記述されている ワイエルストラスの方法などは 可微分性に関してかなりギリギリを攻めているような嫌いがある． それは底が異なる指数関数の増大度を使って頑張っているということだが 急増加数列を使って オリジナルの方法をゆるゆる にしてみたものが以下である．

定理 1 (怠け者のためのワイエルストラス関数).

数列 {rn}n∈ℤ≥0 と {hn}n∈ℤ≥0 は 正の実数列とし，以下の条件を満たすとする．

  1. (A1)

    以下の収束が成り立つ．

    ∑i=0∞1ri<∞
  2. (A2)

    各 hnは奇数であるような整数であり，なおかつ任意のnについて hn+1はhnで割り切れる． 特に，m>nのときhmはhnの奇数倍である．

  3. (A3)

    以下の発散が成り立つ．

    limk→∞(2π⁢hkrk−∑n=0k−1hnrn)=∞.

このとき 以下で定義される関数f:ℝ→ℝ はℝ上連続だが，全ての点において微分不可能である．

f⁢(x)=∑i=0∞cos⁡(hn⁢x)rn.
証明.

まず条件 (A1) と Mテストから fが連続であることがわかる．

今からfが至るところで 可微分ではないことを 証明しよう． 点 p∈ℝを任意に固定する． そして各k∈ℤ≥0 に対してLk∈ℤ≥0 を hk⁢pπ に一番距離が近い整数とし， ukはhk⁢pπ−Lk とする．このとき Lkの定義から |uk|≤1/2である．つまり

hk⁢p=(Lk+uk)⁢π

と |un|≤1/2 が成り立つようなLk と unをとる． そしてxn∈ℝを

xn=1hn⁢(Ln+1)⁢π

と定義する． もちろんこのとき

hn⁢xn=Ln⁢π+π=(Ln+1)⁢π

が成り立つ． このとき|uk|≤1/2 からxk≠pであることに注意しよう． また 定義式から n→∞のとき |xn−a|→0 が成り立つ．

今k∈ℤ≥0 を任意に固定して

Sk=∑n=0k−1cos⁡(hn⁢x)−cos⁡(hn⁢a)rn
Tk=∑n=k∞cos⁡(hn⁢x)−cos⁡(hn⁢a)rn

と定義すると f⁢(xk)−f⁢(a)=Sk+Tk となる． これから|Sk|を上から評価し |Tk| を下から評価していこう．

まずは|Sk| を評価する． 平均値の定理と 任意のx∈ℝに関する不等式|sin⁡(x)|≤1を使うと 関数cos⁡(x)は1-Lipschitz であることがわかる．よって

|Sk|≤∑n=0k−1|cos⁡(hn⁢xk)−cos⁡(hn⁢p)|ri≤∑n=0k−1|hn⁢xk−hn⁢p|ri=∑n=0k−1hi⁢|x−p|rn

が成り立つ． このことから

|Sk|≤|xk−p|⋅∑n=0k−1hiri,

を得る． つまり

|Sk||xk−p|≤∑n=0k−1hiri

がわかる．

次に|Tk|を下から評価する．さて， k≤nとなるn∈ℤ≥0について Ik=hn/hk とすると仮定 (A2) からInは奇数であるような整数になる． よって

hn⁢p=In⁢hk⁢p=In⁢Lk⁢π+In⁢uk⁢π

かつ

hn⁢xk=In⁢hk⁢xk=In⁢(Lk+1)⁢π

である． ゆえに， 加法定理とInが奇数であることから

cos⁡(hn⁢p)=(−1)Lk⁢In⁢cos⁡(In⁢uk⁢π)=(−1)Lk⁢cos⁡(In⁢uk⁢π)

かつ

cos⁡(hn⁢xk)=(−1)(Ln+1)⁢In⁢cos⁡(0)=(−1)Ln+1

である． よってk≤nとなるn∈ℤ≥0 について

cos⁡(hn⁢xk)−cos⁡(hn⁢p)rn=(−1)Ln+1−(−1)Ln⁢cos⁡(In⁢uk⁢π)rn=(−1)Ln+1×1+cos⁡(In⁢uk⁢π)rn

である． このことと， 任意のx∈ℝ について 1+cos⁡(x)≥0 であることから

|Tk|=|(−1)Ln+1⁢∑n=k∞1+cos⁡(In⁢uk⁢π)rn|=∑n=k∞1+cos⁡(In⁢uk⁢π)rn

となる(非負の数の和なので絶対値がちゃんと外れてくれる)． 級数の各項は非負なのでさらに

∑i=k∞1+cos⁡(In⁢uk⁢π)rn≥1+cos⁡(uk⁢π)rk

を得る． ここで |uk|≤1/2なので cos⁡(uk⁢π)≥0となる． ゆえに

1+cos⁡(uk⁢π)rk≥1rk.

を得る． 以上で述べた不等式から |Tk|≥1/rk を導くことができる． ここで|uk|≤1/2 なので

|xh−p|=1hn⁢|un−1|⁢π≤π2⁢hk

がわかる． よって

|Tk||xk−p|≥2π⁢hkrk

がわかる．

数k∈ℤ≥0 の任意性， 以上の|Sk|と |Tk|の評価と， 三角不等式

|f⁢(xk)−f⁢(p)|≥|Tk|−|Sk|

を用いると，任意のk∈ℤ≥0 について

|f⁢(xk)−f⁢(a)xk−a|≥1|xk−p|⁢(|Tk|−|Sk|)≥2π⁢hkrk−∑n=0k−1hnrn

がわかる． 仮定 (A3) から k→∞ のとき

|f⁢(xk)−f⁢(p)xk−p|→∞

がわかる． つまりfは pで微分不可能である． 点 pの任意性から f は至る所微分不可能であることがわかる． ∎

注意.

定理 1の 仮定 (A1), (A2), (A3) を満たす数列hn とrnは存在する． 例えば以下のような例がある．

  1. (1)

    rn=(n+1)2, hn=(2⁢n+1)!!×3n

  2. (2)

    rn=(n+1)2, hn=33n

  3. (3)

    rn=2n, hn=5n2, ここで2と5というのは意味がある． これらの数字は2×2<5 であることが重要である．

  4. (4)

    hn=3↑↑(2⁢n+1), rn=3↑↑(2⁢n), ここで↑↑ はクヌースの二重矢印である．

  5. (5)

    rnを仮定(A1) を満たす関数とし， hn=33⌊rn⌋とする．

よって連続関数で至る所微分不可能な関数が存在することがわかる． 特に例えば

∑n=0∞cos⁡(5n2⁢x)2n

などはそうである．

以上の定理 1 では賢くhnが奇数であることをたくみに用いて Tkの下からの評価をしており，すごいけどめんどくさい．よってもっとガバガバにしよう．

定理 2 (ものぐさワイエルストラス関数).

正の実数からなる二つの数列 {hn}n∈ℤ≥0と {rn}n∈ℤ≥0， 及び正の実数Cは以下の条件を満たすとする．

  1. (B1)

    以下の収束が成り立つ

    ∑n=0∞1rn<∞.
  2. (B2)

    整数N∈ℤ≥0 が存在してk≥Nならば 以下の不等式が成り立つ

    1rk−∑n=k+1∞2rn≥C⋅1rk.

    この不等式からCは結構小さい正の数であることがわかる．

  3. (B3)

    k→∞のとき

    C100⁢hkrk−∑n=0k−1hnrn→∞

    である．

このとき 以下で定義される関数f:ℝ→ℝ はℝ上連続だが，全ての点において微分不可能である．

f⁢(x)=∑i=0∞cos⁡(hn⁢x)rn.
証明.

まず条件 (B1) と Mテストから fが連続であることがわかる．

今からfが至るところで 可微分ではないことを 証明しよう． 点 p∈ℝを任意に固定する． そして各k∈ℤ≥0 に対してLk∈ℤ≥0 を hk⁢p2⁢π に一番距離が近い整数とし， ukはhk⁢p2⁢π−Lk とする．このとき Lkの定義から |uk|≤1である．つまり

hk⁢p=2⁢Lk⁢π+2⁢uk⁢π

と |un|≤1 が成り立つようなLk と unをとる(定理1と取り方が異なることに注意しよう)．

さて今q∈ℝ を固定して関数 g:ℝ→ℝ をg⁢(z)=|cos⁡(z)−cos⁡(q)| と定義する． このとき g⁢(q)=0 で g⁢(0)=|1−cos⁡(q)|=1−cos⁡(q) かつ g⁢(π)=|−1−cos⁡(p)|=1+cos⁡(p) なので cos⁡(q)の符号がプラスか0の時は g⁢(π)≥1 で cos⁡(q)の符号がマイナスのときは g⁢(0)≥1 である． よってgが周期2⁢πの関数であることを用いて さらにgに中間値の定理を適応すると点zであり z∈[0,2⁢π]を満たしなおかつ

|cos⁡(z)−cos⁡(q)|=1

となるものが存在する （こういうのはグラフを書くとなんでこんな点が存在するのかよくわかる）．

上の主張をq=hk⁢pに適応すると， 点 zk∈[0,2⁢π]であって

|cos⁡(zk)−cos⁡(hk⁢p)|=1

となるものを得る． そしてxn∈ℝを

xn=1hn⁢(2⁢Ln⁢π+10⁢π+zk)

と定義する． もちろんこのとき

hn⁢xn=2⁢Ln⁢π+10⁢π+zk

が成り立つ． さらにzkの定義とcosの周期が2⁢πであることから

|cos⁡(hk⁢xk)−cos⁡(hk⁢p)|=1

となることに注意しよう． またxkの定義と |uk|≤1 からxk≠pであることに注意しよう (これを簡単に言うためにわざわざxkの定義式の中には10⁢πが足されている)． また 定義式および， ukとzkが有界であることから n→∞のとき |xn−a|→0 が成り立つ． 特に|uk|≤1 と0≤zk≤2⁢π から，かなりどんぶり勘定で評価して

0<|xk−p|≤100hk

となる．

今 (B2) で述べられているN∈ℤ を取り k≥Nとなる k∈ℤ≥0 を任意に固定して

Sk=∑n=0k−1cos⁡(hn⁢x)−cos⁡(hn⁢p)rn
Tk=∑n=k∞cos⁡(hn⁢x)−cos⁡(hn⁢p)rn

と定義すると f⁢(xk)−f⁢(a)=Sk+Tk となる． これから|Sk|を上から評価し |Tk| を下から評価していこう．

まずは|Sk| を評価する． 平均値の定理と 任意のx∈ℝに関する不等式|sin⁡(x)|≤1を使うと 関数cos⁡(x)は1-Lipschitz であることがわかる．よって

|Sk|≤∑n=0k−1|cos⁡(hn⁢xk)−cos⁡(hn⁢p)|ri≤∑n=0k−1|hn⁢xk−hn⁢p|ri=∑n=0k−1hi⁢|x−p|rn

よって

|Sk|≤|xk−p|⋅∑n=0k−1hiri,

つまり

|Sk||xk−p|≤∑n=0k−1hiri

がわかる．

次に|Tk|を下から評価する．さて， まずxkの定義から

|cos⁡(hk⁢xk)−cos⁡(hk⁢p)rk|=1rk

である. さらに k+1≤nとなるn∈ℤ≥0についての和について， |cos⁡(z)|≤1の不等式を用いて

|∑n=k+1∞cos⁡(hn⁢xk)−cos⁡(hn⁢p)rn|≤∑n=k+1∞2rn

の評価を得る． よって 仮定(B2) と三角不等式を使って

|Tk|≥1rk−∑n=k+1∞2rn≥C⋅1rk

がわかる． つまり

|Tk||xk−p|≥C100⁢hkrk

である．

数k∈ℤ≥0 の任意性， 以上の|Sk|と |Tk|の評価と， 三角不等式

|f⁢(xk)−f⁢(p)|≥|Tk|−|Sk|

を用いると，k≥Nとなる任意のk∈ℤ≥0 について

|f⁢(xk)−f⁢(a)xk−a|≥1|xk−p|⁢(|Tk|−|Sk|)≥C100⁢hkrk−∑n=0k−1hnrn

がわかる． ゆえに 仮定 (B3) から k→∞ のとき

|f⁢(xk)−f⁢(p)xk−p|→∞

がわかる． つまりfは pで微分不可能である． 点 pの任意性から f は至る所微分不可能であることがわかる． ∎

注意.

定理2 の仮定 (B1), (B2), (B3)を満たす数列 hn, rn及びCは存在する．以下のような例がある(たぶん)．Cは省略する．

  1. (1)

    hn=2n!, rn=n!,

  2. (2)

    hn=eeen, rn=een, eは自然対数の底．

  3. (3)

    hn=(n!)n!, rn=nn, ここで00=1 とする．

  4. (4)

    hn=42n5, rn=3n2

  5. (5)

    hn=2↑⁣↑⁣↑n, rn=2↑↑n, 矢印の個数に注意． クヌースの記法である．

特に

f⁢(x)=∑n=0∞cos⁡(2n!⁢x)n!

は至る所微分不可能関数である．

定理 2 の証明の議論ではもはや cos⁡(x)特有の性質， 例えば加法定理などではなく， これが周期関数であること, 連続であること(中間値の定理), リプシッツであること， などしか用いていないので 以下のように一般化できる．

定理 3 (難技者のワイエルストラス関数).

関数w:ℝ→ℝ は周期関数でリプシッツ関数であり， そして定数関数ではないとする． このとき 適切に急増化する正の実数列 {rn}n∈ℤ≥0 と {hn}n∈ℤ≥0 が存在して 以下で定義される関数f:ℝ→ℝ は至る所連続だが至る所微分不可能である．

f⁢(x)=∑n=0∞w⁢(hn⁢x)rn.
証明.

省略． 定理2 と同様にできる． ∎

一つ注意点として ℝ上のリプシッツ関数は ほとんど至る所微分可能であることに注意しよう． そういうある程度滑らかなものから 微分不可能関数を作れるわけである．

定理 3 を適応できる関数でwであってcos⁡x 以外のものは例えば w⁢(x)=infn∈ℤ|x−n| がある． このwから定義される上のような微分不可能関数は Takagi-type の関数と呼ばれているようである． 言うまでもないが高木の例は ∑n=0w⁢(2n⁢x)2n が微分不可能ということを述べており， 上の定理より具体的だし，関数の外と内側で 同じオーダーの数列を扱っているので 高木の例の方が良い結果である． ワイエルストラスの例も同様である．
