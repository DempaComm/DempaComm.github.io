# 松島与三『多様体入門』誤植表・数学的疑義と解決案

単純な誤植216項目、数学的疑義・証明補足57項目、参考注・撤回15項目の三部に分離した（計288項目）。本文中の所在は原本の印刷頁・章節・式番号で示す。

数学的疑義には原記載・問題点・具体的な解決策・反例または修復の根拠・判断を記す。原文の仮定を保つ修復と、仮定を強める修復、正しい結論の説明補足を区別する。

- `main.pdf`：配布用本文。
- `main.tex`：編集可能な単独LuaLaTeX原稿。
- `ERRATA.json` / `ERRATA.csv`：分類・原本位置・原記載・解決案等の全欄。

参考文献にはpaper（paper3510mm）『松島多様体誤植表（第37版3刷）』2017年8月5日版を収録。今回の対象は昭和45年7月15日第5版発行の個体であり、参照先の対象版と区別する。

LuaLaTeXを用い、このフォルダで `lualatex -interaction=nonstopmode -halt-on-error main.tex` を2回実行すると組版できる。原画像やJSONはPDFのコンパイルには不要。
