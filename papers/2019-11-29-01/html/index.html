3 正規性が遺伝する部分集合

改めて Fσ 集合を定義する．

定義 21.

位相空間の部分集合 S が， X の Fσ 集合であるとは， S が X の可算個の閉集合の和集合で書けるときにいう． また， X の部分集合 S が， X の Gδ 集合であるとは S が X の可算個の開集合の共通部分で書けるときにいう．

定義 22.

位相空間 X のふたつの部分集合 A,B が分離的であるとは，

CL⁡(A)∩B=A∩CL⁡(B)=∅

を満たすときにいう．

正規空間において，ふたつの閉集合は分離できるが，一般に分離的なふたつの Fσ 集合を開集合で分離することができる．この性質は見かけ上は正規性よりも強いことを主張しているが，正規性と同値である．

命題 23.

X を正規空間とし， A， B を X のふたつの Fσ 集合で，分離的なものとする．このとき X の開集合 U， V が存在して U∩V=∅ および， A⊂U， B⊂V を満たす．

証明.

X の閉集合からなるふたつの可算族 {Si}， {Ti} は Si⊂Si+1， Ti⊂Ti+1 および

A=⋃iSi,B=⋃iTi

を満たすとする． 開集合の可算族 {Ui}， {Vi} を帰納的に，次を満たすようにとる．

Si⊂Ui⊂CL⁡(Ui)⊂X∖(CL⁡(B)∪⋃k<iCL⁡(Vk)),
Ti⊂Vi⊂CL⁡(Vi)⊂X∖(CL⁡(A)∪⋃k≤iCL⁡(Uk)).

実際，それ以前の集合が選ばれているとき，各右辺は閉集合の有限和の補集合なので開集合である．また， Si⊂A と Ti⊂B であり， A と B は分離的である．さらに，それ以前に選んだ閉包はそれぞれ CL⁡(A) または CL⁡(B) を避ける．したがって，正規性による閉集合の開縮小を順に用いれば， Ui と Vi を選ぶことができる． 任意の i,j について，

Ui∩Vj=∅

に注意しよう． そして，

U=⋃iUi,V=⋃iVi

とすると A⊂U， B⊂V で U∩V=∅ なので，これで命題が証明された． ∎

補題 24.

X の Fσ 集合 S の閉部分集合は， X の Fσ 集合である．

証明.

S=⋃i<ωFi とし，各 Fi を X の閉集合とする． A が S の閉集合ならば，ある X の閉集合 C について A=S∩C と書ける．したがって A=⋃i<ω(Fi∩C) であり， A は X の Fσ 集合である． ∎

系 25.

正規空間の Fσ 集合は正規である．

証明.

S を正規空間 X の Fσ 集合とし， A， B を S の互いに素な閉集合とする．先の補題から， A， B は X の Fσ 集合である．また，これらは X の中でも分離的である．したがって命題23を適用すれば， A， B は S の開集合によって分離できる． ∎

定義 26.

位相空間 X の部分集合 S が一般化 Fσ 集合であるとは，任意の X の開集合 U で S⊂U となるものに対して， Fσ 集合 A が存在して， S⊂A⊂U を満たすときにいう．

補題 27.

X の一般化 Fσ 集合 S の閉集合は X の一般化 Fσ 集合である．

証明.

S の閉集合を A とする．そして， X の開集合 U は A⊂U を満たしているとする．ここで A は S の閉集合なので， X の閉集合 F が存在して S∩F=A を満たす． V=U∪(X∖F) は X の開集合であり， S⊂V を満たす． S は一般化 Fσ 集合であるから， S⊂B⊂V となる X の Fσ 集合 B が存在する． B は Fσ なので B=⋃iCi， Ci は X の閉集合，と表すことができる． そこで Di≔Ci∩F とし， E≔⋃iDi とおく．これはもちろん Fσ 集合である． まず A⊂E である．次に Di⊂V∩F⊂F∩(U∪(X∖F))=U∩F⊂U なので， E⊂U である．以上から A が一般化 Fσ 集合であることがわかる． ∎

命題 28.

X を正規空間とする． X のふたつの分離された一般化 Fσ 集合 A と B に対して， X の開集合 U， V が存在して A⊂U， B⊂V と U∩V=∅ を満たす．

証明.

A⊂X∖CL⁡(B) なので， A が一般化 Fσ 集合であることを用いて A⊂S⊂X∖CL⁡(B) となる Fσ 集合 S が存在する． R=CL⁡(A)∩S は Fσ 集合である． また，同様に B と X∖CL⁡(A) に対して Fσ 集合 T が存在して B⊂T⊂X∖CL⁡(A) を満たす． そして L≔T∩CL⁡(B) と定義する． ここで CL⁡(R)⊂CL⁡(A) なので CL⁡(R)∩L⊂CL⁡(A)∩T=∅ となる．同様に CL⁡(L)∩R=∅ となる．よって先の命題から R と L を分離する開集合が存在する．これは A と B も分離するので，これで証明が終わる． ∎

系 29.

正規空間 X の一般化 Fσ 集合は正規である．

証明.

一般化 Fσ 集合の互いに素なふたつの閉集合は，先の補題によって X の中で分離された一般化 Fσ 集合である．したがって直前の命題を適用すればよい． ∎

以下は同値である．

  1. (1)

    X は正規である．

  2. (2)

    X の分離されたふたつの Fσ 集合は開集合で分離可能である．

注意.

距離空間の任意の部分集合や， ω1 の定常集合などが，一般化 Fσ 集合となる．

4 可算パラコンパクト性とDowkerの定理

この章ではDowkerによる可算パラコンパクト性の特徴付けを紹介する． 以下に三つのコンパクト性の概念を導入する．

定義 31 (可算ハイポコンパクト).

任意の可算開被覆が星形有限な開細分被覆を持つときに可算ハイポコンパクトという．今日ではこの概念は可算強パラコンパクトと呼ばれることがとても多い．

定義 32 (可算パラコンパクト).

任意の可算開被覆が局所有限な開細分被覆を持つときに可算パラコンパクトという．

定義 33 (可算メタコンパクト).

任意の可算開被覆が点有限な開細分被覆を持つときに可算メタコンパクトという．

Dowkerの定理のために次の概念が必要である．

定義 34.

X の可算単調被覆とは，可算被覆 {Ui}i<ω で，

Ui⊂Ui+1

を満たすもののことをいう． また，閉集合の族 {Fi}i<ω が単調減少とは

Fi+1⊂Fi

を満たすときにいう．

Dowkerの定理の前半部分を証明しよう．これはDowkerによる可算パラコンパクト性の特徴付けの中で，被覆による特徴付けに関する部分である．

と定義する．このとき補題37によって， Hs は X の開集合である．ここで， Hs は空集合になることもあることに注意しよう． 次に {Hs} は X の被覆になることを示そう． 任意に x をとってくると， K はコンパクトなので， {x}×K もコンパクトであることと {Ui} が X×K の被覆をなしていることからある s∈[ω]<ω が存在して {x}×K⊂Os となる． よって x∈Hs となる． よって {Hs} は X の開被覆なので X の可算パラコンパクト性より 局所有限な開細分被覆 𝒫 が存在する．各 P∈𝒫 について P⊂Hs⁢(P) となる s⁢(P)∈[ω]<ω を選び， Gs≔⋃{P∈𝒫∣s⁢(P)=s} とおく．局所有限族を親被覆ごとにまとめても局所有限性は保たれるので， {Gs}s∈[ω]<ω は局所有限な開被覆であり， Gs⊂Hs を満たす． 今 𝒰={(Gs×K)∩Ui∣s∈[ω]<ω,i∈s} とすると，これは {Ui} の細分であり，局所有限な開被覆である．よって X×K は可算パラコンパクトである． ∎

5 可算パラコンパクト性の十分条件

定義 43 (monotone normality).

X を位相空間とする． X の互いに素な閉集合の順序対 (A,B) 全体を ℱ とする．また，この ℱ 上に次のように順序 ≺ を定義する． (A,B)≺(C,D) であることを， A⊂C かつ D⊂B であることと定める．

この準備の下，単調正規性を定義する． X の開集合全体を 𝔒⁢(X) と書くことにする． X が単調正規であるとは， X が T1 であって，写像 G:ℱ→𝔒⁢(X) が存在して次を満たすことである．

  1. (1)

    A⊂G⁢(A,B)⊂CL⁡(G⁢(A,B))⊂X∖B

  2. (2)

    (A,B)≺(C,D)⟹G⁢(A,B)⊂G⁢(C,D)

定義 44 (条件(H)).

X を位相空間とする． A,B⊂X， CL⁡(A)∩B=∅ かつ CL⁡(B)∩A=∅ を満たす順序対 (A,B) 全体を ℋ とする．また，この ℋ 上に次のように順序 ≺ を定義する． (A,B)≺(C,D) であることを， A⊂C かつ D⊂B であることと定める．

X が条件 (H) を満たすとは， X が T1 であって， 写像 H:ℋ→𝔒⁢(X) が存在して次を満たすことである．

  1. (1)

    A⊂H⁢(A,B)⊂CL⁡(H⁢(A,B))⊂X∖B

  2. (2)

    (A,B)≺(C,D)⟹H⁢(A,B)⊂H⁢(C,D)

この G を単調正規作用素という．

定義 45 (条件(P)).

X を位相空間とする． p∈X， B が X の閉集合，かつ p∉B である順序対 (p,B) 全体を 𝒫 とする．また，この 𝒫 上に次のように順序 ≺ を定義する． (p,B)≺(q,D) であることを， p=q かつ D⊂B であることと定める．

X が条件 (P) を満たすとは， X が T1 であって， 写像 P:𝒫→𝔒⁢(X) が存在して次を満たすことである．

  1. (1)

    p∈P⁢(p,B)⊂CL⁡(P⁢(p,B))⊂X∖B

  2. (2)

    (p,B)≺(p,D)⟹P⁢(p,B)⊂P⁢(p,D)

  3. (3)

    p≠q ならば P⁢(p,{q})∩P⁢(q,{p})=∅

命題 46.

T1 位相空間 X に対して以下は同値である．

  1. (1)

    X は単調正規

  2. (2)

    X は条件 (H) を満たす．

  3. (3)

    X は条件 (P) を満たす．

証明.

まず最初に単調正規性に関して，写像 G を用いて (A,B)∈ℱ に対して G′⁢(A,B)≔G⁢(A,B)∖CL⁡(G⁢(B,A)) と定義することにより G′ は単調正規作用素になり，さらに (A,B)∈ℱ に対して G′⁢(A,B)∩G′⁢(B,A)=∅ を満たす．よって最初から G は G⁢(A,B)∩G⁢(B,A)=∅ を満たすと仮定しても良い．

さて， ℱ⊂ℋ から (2)⟹(1) は自明である． そして (1)⟹(3) も， (A,B)∈ℱ に対して G⁢(A,B)∩G⁢(B,A)=∅ となることから P⁢(p,C)=G⁢({p},C) と定義すればよい．

最後に (3)⟹(2) を示そう． (A,B)∈ℋ とする．このとき H⁢(A,B)≔⋃p∈AP⁢(p,CL⁡(B)) と定義する．これが条件 (H) の (1),(2) を満たしていることを確認しよう． A⊂H⁢(A,B) は定義から明らかである．任意の p∈A， q∈B に対して P⁢(p,CL⁡(B))⊂P⁢(p,{q}) および P⁢(q,CL⁡(A))⊂P⁢(q,{p}) を満たす． P⁢(p,{q})∩P⁢(q,{p})=∅ なので H⁢(A,B)∩H⁢(B,A)=∅ である． B⊂H⁢(B,A) で H⁢(B,A) は開集合なので CL⁡(H⁢(A,B))⊂X∖B である．条件 (H) の (1) は確かめられた． (A,B)≺(C,D) に対して H⁢(A,B)⊂H⁢(C,D) であることは，条件 (P) の (2) から従う． ∎

注意.

以下では単調正規作用素 G は (A,B)∈ℱ に対して G⁢(A,B)∩G⁢(B,A)=∅ を満たすと仮定する．

補題 49.

LOTSは単調正規

証明.

X をLOTSとして ≤ をその順序とする．また，この順序とは別に X に整列順序 W を導入する． 今から X が条件 (P) を満たすことを証明する．

一般にLOTSの部分集合 S が凸集合であるとは a,b∈S のとき [a,b]⊂S となるときにいう．

p∈X とし， C を X の閉集合で p∉C となるものとする． このとき Con⁡(p,C) を X∖C の部分集合であって p を含む極大な凸集合とする． L⁢(p,C)≔Con⁡(p,C)∩(←,p)， R⁢(p,C)≔Con⁡(p,C)∩(p,→) と定義する．また，（それが存在する場合には）

l⁢(p,C)≔minW⁡L⁢(p,C),r⁢(p,C)≔minW⁡R⁢(p,C)

と定義する．ここで minW は整列順序 W による最小値である．

さて

P⁢(p,C)={(l⁢(p,C),r⁢(p,C))L⁢(p,C)≠∅⁢かつ⁢R⁢(p,C)≠∅⁢のとき[p,r⁢(p,C))L⁢(p,C)=∅⁢かつ⁢R⁢(p,C)≠∅⁢のとき(l⁢(p,C),p]L⁢(p,C)≠∅⁢かつ⁢R⁢(p,C)=∅⁢のとき{p}L⁢(p,C)=R⁢(p,C)=∅⁢のとき

と定義するとこれは条件 (P) を満たすことがわかる．

まず条件 (P) の (1) を満たすことは定義の仕方からわかる．

次に条件 (P) の (2) を満たすことを見よう． p∉C で D⊂C としよう． 定義から Con⁡(p,C)⊂Con⁡(p,D) がわかる．よって， L⁢(p,C)⊂L⁢(p,D) と R⁢(p,C)⊂R⁢(p,D) がわかる．さらに， x∈L⁢(p,D)∖L⁢(p,C) と y∈L⁢(p,C) について x<y となることがわかる． 同様に x∈R⁢(p,D)∖R⁢(p,C) と y∈R⁢(p,C) について y<x がわかる． これらのことから l⁢(p,D)≤l⁢(p,C) と r⁢(p,C)≤r⁢(p,D) が従う．よって条件 (P) の (2) が成り立つ．

最後に条件 (P) の (3) を示そう．互いに異なる p,q∈X をとる． このとき p<q と仮定しても良い． すると L⁢(p,{q})=(←,p)， R⁢(p,{q})=L⁢(q,{p})=(p,q)， R⁢(q,{p})=(q,→) がわかるので条件 (P) の (3) は成り立つ． ∎

    M は ω の無限部分集合

  2. (2)

    i⁢(xn)=n

  3. (3)

    任意の n∈M と m>n となる任意の m∈M に対して xn∈Vm−n⁢(xm) が成り立つ．

U⁢(pk)⊂W⁢(pk)⊂Vk⁢(pk)⊂E⁢(pk,X∖Dk)⊂E⁢(pk,X∖{pj})

pk∈W⁢(pj)⊂Vj⁢(pj)⊂Vj−k⁢(pj)

Vj−k⁢(pj)⊂E⁢(pj,X∖Dj)⊂E⁢(pj,X∖{xn})

と定義する．もし V⁢(f)∩V⁢(g)≠∅ ならば，任意の β<α で V⁢(f,β) と V⁢(g,β) が交わるので，両者は等しい．したがって V⁢(f)=V⁢(g) であり， 𝒥α は互いに素である．

最後に三条件を確かめる． i<α とし， P=V⁢(f)， Q=V⁢(f,i) とおけば P⊂Q である． P が ℋ のふたつ以上の元と交わるならば， V⁢(f,i) もそうである．このとき i+1<α であり， tV⁢(f,i+1)≠tV⁢(f,i) である．しかも tP≤tV⁢(f,i+1)≤tV⁢(f,i) なので，真に減少する座標を見れば tP≠tQ が従う．一方， Q が ℋ の高々ひとつの元としか交わらないならば 𝒪⁢(Q)={Q} であり，以後の全ての段階で f を含む元は Q のままなので P=Q である．

∎

以後， f∈⋃ℋ と α<κ+ に対し， V⁢(f,α) で f を含む 𝒥α の唯一の元を表す．

補題 103.

I を無限基数とする． F の中の列 {si}i<I は，任意の i<j<I と任意の α<κ について sj⁢(α)≤si⁢(α) と sj≠si を満たしているとする． このとき， I≤κ である．

証明.

各 ξ+1<I に対して， sξ+1⁢(αξ)<sξ⁢(αξ) となる座標 αξ<κ をひとつ選ぶ．固定した座標 α<κ がこのように選ばれる回数は有限である．実際，無限回選ばれれば，その座標に順序数の無限降下列が生じる．したがって，後続段階の総数は高々 κ⋅ω0=κ である． I は無限基数なので後続段階の総数は I であり， I≤κ を得る． ∎

命題 104.

X の疎な閉集合の族 ℋ に対して， 互いに素な開集合の族 {GA}A∈ℋ が存在して A⊂GA を満たす． つまり X は族正規である．

証明.

∅∈ℋ ならば G∅=∅ とし，以下では ℋ の非空な元だけを考える．各 f∈⋃ℋ に対して， af<κ+ を V⁢(f,af) が ℋ の高々ひとつの元としか交わらないように取る．このような af は存在する．実際，存在しなければ {tV⁢(f,α)}α<κ+ は長さ κ+ の真の単調減少列となり，直前の補題に反する．各 A∈ℋ に対して

GA≔⋃f∈AV⁢(f,af)

と定義する． A⊂GA はわかる． 互いに素であることを示そう． A,B∈ℋ， A≠B， f∈A， g∈B とする． n≔max⁡{af,ag} とおく． V⁢(f,af) と V⁢(g,ag) はそれぞれ ℋ の高々ひとつの元としか交わらないので， V⁢(f,af)=V⁢(f,n)， V⁢(g,ag)=V⁢(g,n) である．これらは 𝒥n の元である．もし両者が等しければ，その集合は A と B の双方に交わり， V⁢(f,af) の選び方に反する．よって両者は相異なり，互いに交わらない． よって {GA}A∈ℋ は互いに素である．

これで X が族正規であることがわかった．

∎

定理 105.

任意の無限基数 κ について， κ-Dowker space が存在する．特にDowker spaceは存在する．

注意.

κ=ω0 の場合にも命題90の列を用いた上の一様な構成が適用できる．一般のZFCでは，この構成の λn をそのまま ωn に置き換えられるとは限らない．Rudinによる最初の例では，正の整数を添字に用いる別の構成がなされている[12]．

7.1 応用

κ-Dowker space の存在から次のことがわかる．

定理 106 (森田の第一予想の肯定的解決).

位相空間 X は T4 とする． 任意の T4 空間 Y との直積 X×Y が T4 ならば， X は離散空間である．

以下ではこの予想を κ-Dowker space の存在から証明していこう．

まず次の補題が必要になる．これはDowkerによる可算パラコンパクト性の特徴づけの類似である．

補題 107.

位相空間 Y には濃度が κ の非閉な部分空間 Z={pi}i<κ が存在し，さらに Y の部分空間で濃度が <κ のものは全て閉集合であるとする． このとき，もし T4 空間 X と Y との直積 X×Y が正規ならば， X は κ-Dowker space ではない． つまり， ⋂i<κDi=∅ を満たす任意の X の単調減少な閉集合の族 {Di}i<κ に対して Di⊂Gi となる開集合の族 {Gi}i<κ が存在して

⋂i<κGi=∅

を満たす．

証明.

{Di}i<κ を X の単調減少な閉集合族で ⋂i<κDi=∅ となるものとする．この集合族に対し， Di⊂Gi で， ⋂i<κGi=∅ となるものを構成する． X×Y の部分集合 A を

A≔⋃i<κDi×{pi}

と定義する．この集合が X×Y の閉集合であることを示そう． (x,y)∉A としよう．

[Case 1]

x∈D0 のとき このとき x∉DN となる最小の N<κ をとる． すると j<N となる j については x∈Dj なので，任意の j<N について， y≠pj である． Y の濃度が κ 未満の部分空間は閉集合だと仮定しているので， {pj∣j<N} は閉集合である．よって MN≔Y∖{pj∣j<N} は開集合であり， (X∖DN)×MN が A と交わりを持たない (x,y) の開近傍となる．

[Case 2]

x∉D0 のとき このときには (X∖D0)×Y が A と交わらない (x,y) の開近傍になる．

以上のことから A は閉集合である．

Z は閉集合ではないので， q∈CLY⁡(Z)∖Z を取る．

さて， B≔X×{q} とすると， A と B は交わりを持たない X×Y の閉集合であるから， X×Y の正規性から，交わりを持たないふたつの X×Y の開集合 U,V で

A⊂U,B⊂V

となるものが存在する．

ここで Gi≔{x∈X∣(x,pi)∈U}=U⁢[pi] と定義する． すると， Gi は開集合であり， A⊂U から Di⊂Gi を満たす． また， x∈X を任意に取ると， (x,q)∈B⊂V なので， x の近傍 S と q の近傍 M が存在して， S×M⊂V となる． q∈CLY⁡(Z) なので N<κ が存在して pN∈M となる． U∩V=∅ なので，特に (x,pN)∉U である． つまり， x∉GN である．よって ⋂i<κGi=∅ がわかる． これで証明が終わる． ∎

証明すべきことをもう一度のべる．

定理 108 (森田の第一予想の肯定的解決).

位相空間 X は T4 とする． 任意の T4 空間 Y との直積 X×Y が T4 ならば， X は離散空間である．

証明.

位相空間 X に対して基数関数を次のように定義する．

nc⁡(X)≔min⁡{κ∣κ≤card⁡(X)⁢であり，⁢X⁢には濃度⁢κ⁢の非閉部分空間が存在する．}

min の中身が空集合の場合には nc⁡(X)=∞ と書くことにする． X が T1 のときには nc⁡(X) は有限の値を取らない．つまり nc⁡(X) は無限基数かもしくは ∞ の値をとる．また， nc⁡(X)=∞ と X が離散空間であることは同値である．

本題に入ろう．もし T4 空間 X が離散でないとすると， nc⁡(X) は無限基数となり， 先の補題の対偶から X と nc⁡(X)-Dowker space D との積は T4 ではない．しかし， D は T4 であるから，これは X の仮定に反する．よって X は離散空間である． ∎

森田の三つの予想はすでにZFC公理系の下で全て肯定的に解決されている．

8 補記：森田予想について

一般に以下のことが成り立つ．

定理 109.

X を T1 空間とする． 任意の離散空間 Y に対して X×Y が T4 であるための必要十分条件は， X が T4 であることである．

定理 110.

X を T1 空間とする． 任意の距離化可能空間 Y に対して X×Y が正規であるための必要十分条件は， X が T4 な P-space であることである．

定理 111.

X を距離化可能空間とする． 任意の可算パラコンパクト T4 空間 Y に対して X×Y が T4 であるための必要十分条件は， X が σ -局所コンパクトな距離化可能空間であることである．

これら三つの定理の「双対」が森田の三つの予想である．これは1976年に森田紀一によって提案された．

予想 1.

X を T1 空間とする． 任意の T4 空間 Y に対して X×Y が T4 であるための必要十分条件は， X が離散空間であることである．

予想 2.

X を T1 空間とする． 任意の T4 な P-space Y に対して X×Y が T4 であるための必要十分条件は， X が距離化可能空間であることである．

予想 3.

X を T1 空間とする． 任意の σ -局所コンパクトな距離化可能空間 Y に対して X×Y が T4 であるための必要十分条件は， X が可算パラコンパクトな T4 であることである．

予想 1 はM. Atsujiによって κ-Dowker space の存在が予想 1 を解くことが指摘され，1978年にM. E. Rudinが κ-Dowker space を構成することによって(ZFCで)肯定的に解決された([13])． Atsujiが前セクションであげた κ-Dowker space が存在すれば，森田の第一予想が解けると指摘して，Rudinがそれを構成したと[13]に書いてある．Atsujiは直積空間が正規になるための必要十分条件の研究をしており，その研究結果からDowker spaceを一般化した κ-Dowker space の条件が予想 1 を解くことがわかったのだと思われる．

1985年にA. Bes̆lagićとM. E. Rudinは V=L の仮定の下で予想 2， 3 を証明した．([3]) 予想 3 は1998年にBaloghによって(ZFCで)肯定的に解決された．([1]) 予想 2 は2001年にBaloghによって(ZFCで)肯定的に解決された．([2]) 実は予想 2 の成立から予想 1 と 3 の成立が従うことが知られている．([5])
