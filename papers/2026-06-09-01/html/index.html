この文章では Bing’s shrinking criterion を証明する． このcriterion は距離化可能空間 X とその商空間 X/R が同相になるための 条件の 研究の結果見出されたものである． なぜそのようなものを研究していたのかというと， 「三次元球面内の二次元球面の埋め込み像によって 二分される領域は常に 三次元球体に同相というわけではない」という， Jordanの曲線定理の高次元化は無条件に成り立たないという J. 1 パラコンパクト性などの準備

被覆に関する名称や記号などは [森田位相空間論] を参考にした．

位相空間 X について， その部分集合の族 𝒜 が X の 被覆 であるとは ⋃A∈𝒜A=X が成り立つことである． 位相空間 X の 被覆全体の集合を cov~⁢(X) とかき， X の 開集合からなる被覆 全体の集合を cov⁢(X) と書くことにする． もちろん cov⁢(X)⊂cov~⁢(X)である． 位相空間 X の二つの部分集合族 𝒜 と ℬ について 𝒜がℬの細分である とは 任意の A∈𝒜 についてある B∈ℬ が存在して A⊂B となるときにいう． このとき 𝒜≺ℬ と書く． この文章では主に cov⁢(X) の元についてその細分などを考えることになるだろう．

定義 1 (パラコンパクト).

位相空間 X がパラコンパクトであるとは X の任意の開被覆 𝒰∈cov⁢(X) について 局所有限な開被覆 𝒱∈cov⁢(X) が存在して 𝒱≺𝒰 が成り立つときにいう．

位相空間 X の部分集合 S と 部分集合族 𝒜 について St⁢(S,𝒜) を

St⁢(S,𝒜)=⋃{A∈𝒜∣A∩S≠∅}

と定義する． S={x} のときは St⁢(x,𝒜) と略記する．

位相空間 X の部分集合族 𝒜 について 𝒜∗ という記号で部分集合の族 {St⁢(A,𝒜)∣A∈𝒜} という集合族を表す． もちろん 𝒜∗≺𝒜 である． また， 𝒜Δ という記号で部分集合の族 {St⁢(x,𝒜)∣x∈X} という集合族を表す．

定義 2 (星形細分).

位相空間 X の部分集合族 𝒰 と 𝒱 について 𝒱 が 𝒰 の 星形細分 であるとは 𝒱∗≺𝒰 が成り立つときにいう．

定義 3 (星形細分).

位相空間 X の部分集合族 𝒰 と 𝒱 について 𝒱 が 𝒰 の Δ細分 であるとは 𝒱Δ≺𝒰 が成り立つときにいう．

一般に 𝒜∗≺𝒜Δ⁢Δ が成り立つことに注意しよう． ここで 𝒜Δ⁢Δ は (𝒜Δ)Δ という意味である．

一般の位相空間の上でも 距離関数のように点同士の近さを測ることができれば 便利である． ここではそのようなものとして 擬距離 を用いる． 空間 X に対して 関数 d:X×X→[0,∞) が X上の擬距離関数 であるとは d が対称性と三角不等式を満たすときにいう． 非退化性は成り立たないことに注意しよう． 一般的な空間で距離関数を扱う代償として 異なる2点 x,y∈X について d⁢(x,y)=0 が起こりうることも許容するのである． 擬距離関数 d と r∈(0,∞) に対して V⁢(x,r;d) で x を中心とする 半径 r の開球を表すことにする．

位相空間 X に対して ConPsMetrb⁢d⁢(X) で X 上の連続で有界な擬距離関数全体を表すことにする． ここで連続性は 写像 d:X×X→[0,∞) としての連続性という意味である． 有界性も d の像が [0,∞) の中で有界な集合になっているという常識的な意味で使う(この文書では有界な擬距離しか扱わない． なぜならlimitation topologyを記述するのにはそれしか用いないからである)． また d が連続であるとき V⁢(x,r;d) は X の開集合になることに注意しよう (開球全体が開基になると距離化可能性が同値である．つまり一般的な状況においてこれらが開基になることは期待できないということである)． また AdMetrb⁢d⁢(X) で X 上の有界な距離関数であって X と同じ位相を生成するもの全体を表すことにする． もちろんこれは空集合になることもある． 一般に X が距離化可能 であることと AdMetrb⁢d⁢(X)≠∅ が同値であることに注意しよう．ここで距離化可能性から有界 な距離関数の存在が言えるのかどうか気になった人もいるかもしれないが， X と同じ位相を生成する距離関数 d に対して min⁡{d,1} も X と同じ位相を生成する距離関数になるので大丈夫である．試みられよ． またこの集合の記号はAdmissible Metrics という意味である． そして AdComMetrb⁢d⁢(X) で X と同じ位相を生成する 完備距離関数 全体を表すことにする． X が距離化可能であったとしても AdComMetrb⁢d⁢(X) は空集合になりうる． 一般に X が 完備距離化可能 であることと AdComMetrb⁢d⁢(X)≠∅ が同値である． 上で似たような注意をしたが， d が X と同じ位相を生成する完備距離関数のときに min⁡{d,1} も同じ位相を生成する有界な完備距離関数になることに注意しよう． 試みられよ． また 𝒪⁢(r;d)={V⁢(x,r;d)∣x∈X} と定義しておく．

以下の命題はパラコンパクトハウスドルフ空間の 被覆の話をする場合に擬距離の有用性を物語る．

この定理自体は [22, Theorem 7.4], [17, Remark 4], [5, Theorem 14], [8, Metrization Lemma 12, p.185], [6, Theorem 2.1], [児玉-永見, 定理16.4] などで証明が知られている．

命題 4.

X をパラコンパクトハウスドルフ空間とする． このとき 任意の 𝒰∈cov⁢(X) に対して d∈AdMetrb⁢d⁢(X) が存在して 𝒪⁢(1;d)={V⁢(x,1;d)∣x∈X} が 𝒰 を細分する．

証明.

今から X 上の連続な擬距離関数 d であって 𝒲=𝒪⁢(1;d)={V⁢(x,1;d)∣x∈X} が 𝒰 を細分するものを構成する． X はパラコンパクトであるから 単位の分割 {ga:X→[0,1]}a∈A が存在して {ga−1⁢((0,1])∣a∈A}が 局所有限かつ 𝒰 を細分するものが存在する ([ブルバキ位相4, 系, p56], [宮島関数解析, 定理7.44] [13, Proposition 2], [17, Corollary 2.7.3])． この ga−1⁢((0,1]) を gaの サポートと呼ぶ． そして ϕ:X→(0,1] を ϕ⁢(x)=supa∈Aga⁢(x) と定義すると ga の サポートが局所有限であることから ϕ は X 上連続である． ここで各 a∈A について fa:X→(0,1] を

(1.1) fa⁢(x)=2ϕ⁢(x)⋅min⁡{ga⁢(x),ϕ⁢(x)2}.

と定義する． すると fa は連続であり，以下の性質を満たす．

  1. (A1)

    fa のサポート全体の族 {fa−1⁢((0,1])}a∈A は X の局所有限な開集合族で被覆でありさらに 𝒰 の細分となっている．

  2. (A2)

    族 {fa−1⁢({1})}a∈A は X の被覆になっている．

上記の性質が成り立つのを少し確認しよう． まず定義から fa−1⁢((0,1])=ga−1⁢((0,1]) が成り立つので (A1) は成り立つ． そして x∈X に対して ϕ⁢(x)=gp⁢(x) となる p∈A を取れば fp⁢(x)=1 となるので (A2) も成り立つ． さて ℓ1⁢(A) という記号で 写像 w:A→ℝ であって ∑a∈A|w⁢(a)|<∞ となるもの全体を表すことにする． そして ∥∗∥ℓ1 で ℓ1⁢(A) 上の ℓ1 ノルムを表すことにする． 各 a∈A について 𝐞a という記号で ℓ1⁢(A) の元で 𝐞a⁢(p)=1 (p=aのとき); 上記以外のとき 𝐞a⁢(p)=0 となるものを表すことにする． 写像 ψ:X→ℓ1⁢(A) を ψ⁢(x)=∑a∈Afa⁢(x)⋅𝐞a と定義する． (A1) より fa のサポート全体が局所有限なので ψ はwell-definedで尚且つ連続であることがわかる． そして d:X×X→[0,∞) を d⁢(x,y)=∥ψ⁢(x)−ψ⁢(y)∥ℓ1 と定義すれば ψの 連続性から d も X×X 上で 連続であることがわかる． 今から 𝒲=𝒪⁢(1;d)={V⁢(x,1;d)∣x∈X} が 𝒰 の細分になっていることを証明しよう． 任意の x∈X をとる． そして (A2)を用いて fb⁢(x)=1 となる b∈A をとる． そして y∈V⁢(x,1;d) について |fb⁢(y)−fb⁢(x)|≤∥ψ⁢(x)−ψ⁢(y)∥ℓ1=d⁢(x,y)<1 が成り立つ． よって |fb⁢(y)−fb⁢(x)|<1と fb⁢(x)=1, を組み合わせると fb⁢(y)>0 がわかる． よって U⁢(x,1;d)⊂fb−1⁢((0,1]) である．再び(A1)より ある U∈𝒰 が存在して fb−1⁢((0,1])⊂U なので V⁢(x,1;d)⊂U である． よって 𝒲=𝒪⁢(1;d)={V⁢(x,1;d)∣x∈X} は 𝒰 の細分になっている．

ところで d が有界じゃない可能性もあるが， その場合は min⁡{d,2} で置き換えれば良い． 中心が x で半径 1 の開球は d でも min⁡{d,2} でも同じ集合になる． ∎

命題 5.

位相空間 X はパラコンパクトであるとする． このとき 任意の開被覆 𝒰∈cov⁢(X) についてこれの 星形細分 𝒱∈cov⁢(X) が存在する．

証明.

命題 4 で保証される d∈AdMetrb⁢d⁢(X) をとる． そして 𝒲=𝒪⁢(1;d)={V⁢(x,1;d)∣x∈X} で 𝒱=𝒪⁢(1/3;d)={V⁢(x,1/3;d)∣x∈X} と定義すると 三角不等式から 𝒱∗≺𝒲 であり， 命題 4 からわかる 𝒲≺𝒰 と合わせると 𝒱∗≺𝒰 が成り立つ． これで証明が終わる． ∎

別証明([18]).

任意の開被覆 𝒰 に Δ細分が存在することを示せば， ２回 Δ細分を取ることで 星形細分を得ることができる． 空間 X はパラコンパクトなので 最初から 𝒰 は局所有限であると仮定しても良い． この 局所有限開被覆に Δ開細分被覆が存在することを言えば良い． 空間 X の正規性と 𝒰 の局所有限性から 閉被覆 {FU|U∈𝒰} が存在し FU⊂U を満たす． 各点 x∈X について 𝒰 の局所有限性を担保する近傍の一つを V⁢(x) とする． 次に各点 x∈X について

A⁢(x)={U∈𝒰|V⁢(x)∩U≠∅},
B⁢(x)={U∈𝒰|x∈U},
C⁢(x)={U∈A⁢(x)|x∉FU}

と置く． すると FU⊂U から A⁢(x)=B⁢(x)∪C⁢(x) である． さて

W⁢(x)=V⁢(x)∩⋂S∈B⁢(x)S∩⋂T∈C⁢(x)(X∖FT)

と定義すると, {FU} や 𝒰 の局所有限性から W⁢(x) は開集合である． そして x∈W⁢(x) なので 𝒲={W⁢(x)}x∈X は開被覆となっている． 𝒲 が 𝒰 の Δ細分となることを見よう． まず任意に p∈X を与えると {FU|U∈𝒰} が被覆なので p∈FU となる U∈𝒰 が存在する． このとき U∈B⁢(p) なので

W⁢(p)⊂U

である． さて 𝒲 が 𝒰 の Δ細分であることを示すには， うえで取った U について

p∈W⁢(x)⟹W⁢(x)⊂U

がわかれば良い． 実際 p∈W⁢(x) ならば W⁢(p)∩U≠∅ なので U∈A⁢(x) である． そして p∈W⁢(x) かつ p∈FU なので W⁢(x)∩FU≠∅ でもある． よって U∉C⁢(x) となるから U∈B⁢(x) である． そして W⁢(x) の定義から W⁢(x)⊂U なので 𝒲 が 𝒰 の Δ細分であることがわかる． ∎

2 関数空間のlimitation topology

ここでは [20] に則って， 関数空間の limitation topology を導入して基本的な性質を明らかにしていこう． 文献 [17], [16], [10], [7], [3], [11], [12] も参考にした．

定義 6.

X と Y を位相空間とする． このとき C⁢(X,Y) で X から Y への連続写像全体を表すとする． 次に 𝒰∈cov⁢(Y) と f,g∈C⁢(X,Y) に対して fとgが𝒰-closeである とは 高々 2 点集合の族 {{f⁢(x),g⁢(x)}∣x∈X} が 𝒰 の細分になっているときにいう． つまり任意の x∈X について U∈𝒰 が存在して {f⁢(x),g⁢(x)}⊂U となるということである． また 𝒰∈cov⁢(Y) と f∈C⁢(X,Y) に対して B⁢(f,𝒰) を f に 𝒰-close な g∈C⁢(X,Y) 全体の集合とする．

定義 7.

位相空間 X, Y と d∈ConPsMetrb⁢d⁢(Y) について d^ を f,g∈C⁢(X,Y) に対して d^⁢(f,g)=supx∈Xd⁢(f⁢(x),g⁢(x)) と定義する． さて f∈C⁢(X,Y), r∈(0,∞), d∈ConPsMetrb⁢d⁢(Y) について N⁢(f,r;d) を g∈C⁢(X,Y) であって d^⁢(f,g)<r となるもの全体とする．

命題 8.

X を位相空間とし， Y をパラコンパクトハウスドルフ空間とする． このとき C⁢(X,Y) の部分集合族 {N⁢(f,1;d)∣f∈C⁢(X,Y),d∈ConPsMetrb⁢d⁢(Y)} は開基の条件を満たす．

証明.

任意に f,g∈C⁢(X,Y) と d,e∈ConPsMetrb⁢d⁢(Y) を与える． そして今から任意の h∈N⁢(g,1;e)∩N⁢(f,1;d) に対して ある q が存在して N⁢(h,1;q)⊂N⁢(g,1;e)∩N⁢(f,1;d) となることを証明する． まず α=1−e^⁢(h,g)>0 かつ β=1−d^⁢(h,f)>0 とおく．そして

q=α−1⁢e+β−1⁢d

とする． そして w∈N⁢(h,1;q) を任意にとる． このとき q^⁢(w,h)<1 であるから q の定義から特に e^⁢(w,h)<αでもある． すると

e^⁢(w,g)≤e^⁢(w,f)+e^⁢(f,g)<α+e^⁢(f,g)≤1

であるから w∈N⁢(g,1;e) である． 同様に w∈N⁢(f,1;d) である． 以上で主張の中の族が開基の条件を満たすことがわかった． ∎

命題 9.

X を位相空間とし， Y をパラコンパクトハウスドルフ空間とする． このとき C⁢(X,Y) の部分集合族 {B⁢(f,𝒰)∣f∈C⁢(X,Y),𝒰∈cov⁢(Y)} は {N⁢(f,1;d)∣f∈C⁢(X,Y),d∈ConPsMetrb⁢d⁢(Y)} と同じ位相を生成する．

証明.

任意に f∈C⁢(X,Y) と 𝒰∈cov⁢(Y) を取る． 今から d∈ConPsMetrb⁢d⁢(Y)が存在して N⁢(f,1;d)⊂B⁢(f,𝒰) を示そう． 命題 4 より d∈ConPsMetrb⁢d⁢(Y) が存在して {U⁢(x,1;d)∣x∈X} が 𝒰 の細分となる． 任意に g∈N⁢(f,1;d) をとる． このとき d^⁢(f,g)<1 であることから 任意の x∈X について g⁢(x)∈V⁢(f⁢(x),1;d) となることが導かれる． このとき d の取り方からある U∈𝒰 が存在して V⁢(f⁢(x),1;d)⊂U となる． つまり {f⁢(x),g⁢(x)}⊂U となる． よって f と g は 𝒰-close であるから g∈B⁢(f,𝒰) となる． つまり N⁢(f,1;d)⊂B⁢(f,𝒰) である．

今度は d∈ConPsMetrb⁢d⁢(Y) を任意に与えて これに対して 𝒰∈cov⁢(Y) が存在して B⁢(f,𝒰)⊂N⁢(f,1;d) を満たすことを見よう． 今 𝒰=𝒪⁢(1/100;d)={V⁢(x,1/100;d)∣x∈X} としよう． すると任意の g∈B⁢(f,𝒰) と x∈X に対して p∈X が存在して f⁢(x),g⁢(x)∈V⁢(p,1/100;d) が成り立つ． よって任意の x∈X について d⁢(f⁢(x),g⁢(x))<1/2 なので特に d^⁢(f,g)<1 である． つまり g∈N⁢(f,1;d) となる． これは B⁢(f,𝒰)⊂N⁢(f,1;d) ということである． 以上から命題の主張が成り立つことがわかった． ∎

定義 10.

以上の命題 8 にて言及されている族 (あるいは同じことだが命題 9の族) によって生成される位相を C⁢(X,Y) の limitation topologyと呼ぶ(制約位相?和定訳は無いようである)． この文書では関数空間にはこの位相しか考えないので他の位相とまぎれない．

また， このlimitation topologyの開基は複数あるので， 紹介しよう．

X を位相空間とし， Y をパラコンパクトハウスドルフ空間とする． このとき C⁢(X,Y) の部分集合族 {N⁢(f,r;d)∣f∈C⁢(X,Y),d∈ConPsMetrb⁢d⁢(Y),r∈(0,∞)} は C⁢(X,Y) の開基になる．

証明.

一般に N⁢(f,r;d)=N⁢(f,1;r−1⋅d) が成り立つのでわかる． ∎

補題 12.

X を位相空間とし， Y をパラコンパクトハウスドルフ空間とする． そして f∈C⁢(X,Y), d,e∈AdMetrb⁢d⁢(Y) とする． このとき以下が成り立つ．

(2.1) N⁢(f,1;d+e)⊂N⁢(f,1;d)∩N⁢(f,1;e)
証明.

3 Bing’s shrinking criterion

Bing’s shrinking criterion についての歴史などは [10] や [7] を参照のこと．

X と Y を位相空間とする． このとき 連続写像 f:X→Y が near-homeomorphism であるとは C⁢(X,Y) 内の f の 任意の 近傍 に同相写像 h:X→Y が存在するときにいう． もちろんnear-homeomorphismが存在すれば， X と Y は同相である．

位相空間 Z に対して Homeo⁢(Z) で同相写像 f:Z→Z 全体の集合を表す． そして Homeo⁢(Z) でnear-homeomorphism Z→Z 全体の集合を表す．

X と Y を位相空間とし， f:X→Y を連続写像， d∈ConPsMetrb⁢d⁢(Y) とする． このとき f∗⁢d∈ConPsMetrb⁢d⁢(X) を f∗⁢d⁢(x,y)=d⁢(f⁢(x),f⁢(y)) と定義する．

以下の定理の形のcriterion はおそらく最も一般的な形であり， 論文 [20] で導入された． 論文 [21] も参照のこと． このshrinkability の概念は [10] の中の tightly shrinkable に相当すると思われる．
