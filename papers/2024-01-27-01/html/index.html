ベールの範疇定理

電波通信 キトラ　ナンブ
HTML変換日：2026年7月26日

この文章では， ベールの範疇定理は コンパクトハウスドルフの場合に 証明すれば 完備距離空間および 局所コンパクトハウスドルフの場合は そこから従うことを紹介する． Čech完備性を用いると 統一的に扱えるのである．

ベール空間の基本的な話は [電波通信１] などを 参照のこと．

1 ベール空間

定義 1.

この文章では 位相空間 X が ベール であるとは X の稠密な開集合の 任意の可算族 {Un}n∈ℤ≥0 について ⋂n∈ℤ≥0 がX の中で稠密になる時にいうことにする．

定理 2.

任意の空ではないコンパクトハウスドルフ空間 X はベール空間である．

証明.

Xの稠密開集合の可算族 {Ui}i∈ℤ≥0 を任意に与える． 空間Xがベールであることを証明するには ⋂i∈ℤ≥0Ui がX の中で稠密であることを示せば良い． 空間Xの空でない開集合O を与える． 今から⋂i∈ℤ≥0Ui とOが 交わりを持つことを証明する． 帰納的に以下の条件を満たす可算族 {Pi}i∈ℤ≥0 を構成する．

  1. (1)

    任意の i∈ℤ≥0 について Pi は 空でない 開集合 である．

  2. (2)

    任意の i∈ℤ≥0 について CL⁢(Pi+1)⊂Pi を満たす．

  3. (3)

    任意のi について CL⁢(Pi)⊂O∩Ui を満たす．

まずP0 は 適当に P0=O∩U0 とか定義すれば良い． Piまで定義されたときPi+1 を以下のように定義する． 今 Ui+1 は稠密なので Pi∩Ui+1 は空でない開集合である． 適当に点 p∈Pi∩Ui+1 をとって 空間X の正則性を用いると 開集合Pi+1 であって p∈Pi+1 でありなおかつ CL⁢(Pi+1)⊂Pi∩Ui+1 を満たすものが取れる． このとき 明らかに CL⁢(Pi+1)⊂Pi であり なおかつPi⊂O なので CL⁢(Pi+1)⊂O∩Pi である．

さて以上を踏まえて族 {CL⁢(Pi)}i∈ℤ≥0 を考えるとこれはnested なので特に 有限交差性を持つ． よって Xのコンパクト性から ⋂i∈ℤ≥0CL⁢(Pi) は空でなない． さてこのとき

⋂i∈ℤ≥0CL⁢(Pi)⊂(O∩⋂i∈ℤ≥0Ui)

なので O∩⋂i∈ℤ≥0Ui は空ではない． よって Oの任意性から ⋂i∈ℤ≥0Ui がXの中で稠密であることがわかった． ∎

補題 3.

Xをベール空間とする． このとき Xの稠密な Gδ集合はベール空間になる．

証明.

SをXの任意の稠密な Gδ集合はベール空間とする． Sの稠密な開集合の可算族 {Ui}i∈ℤ≥0 を任意にとる． 今から⋂i∈ℤ≥0Ui がSの稠密部分集合であることを示す． まずSの相対位相の定義から Xの開集合族 {Vi}i∈ℤ≥0 が存在して Vi∩S=Ui となる． このとき SがXの中で稠密であることと S∩Vi=Ui がSの稠密部分集合であることから Viは Xの稠密部分集合になる． ここで Sも Xの稠密部分集合であり Gδ 集合なので

S∩⋂i∈ℤ≥0Vi(=⋂i∈ℤ≥0Ui)

は X の稠密な開集合の可算族の共通部分として 表すことができる． よって X がベール空間であることから S∩⋂i∈ℤ≥0Vi は Xの稠密部分集合である． この集合はSの部分集合でもあるので 特にSの中でも稠密になる． よって ⋂i∈ℤ≥0Ui はS の中 で稠密である． 以上で S がベール空間であることがわかる． ∎

2 Čech完備空間

定義 4.

X を位相空間とする． このとき X の コンパクト化 とは コンパクトハウスドルフ空間 K であって 位相的埋め込み f:X→K であって f⁢(X) が Kの中で稠密である ようなものが存在するものをいう． この定義から Xは Kの 部分空間とみなせるので 以下では Xのコンパクト化を考える時には Xはそのコンパクト化の 部分集合と考えることにする．

注意.

コンパクト化は一意的では全くなく， 一般にはたくさん存在する(コンパクト化が一個しかないやつもある, ω1とか)． また， コンパクト化の定義から Xがコンパクト化を持つならば Xは完全正則であることがわかる． 逆に Xが完全正則ならば X にはストーンチェックコンパクト化が存在するので コンパクト化をもつ．

定義 5.

位相空間 Xについて その開被覆の可算族 𝐔={𝒰n}n∈ℤ≥0 が 完備列 であるとは， Xの任意のフィルター 𝔉 について もしも任意のn∈ℤ≥0 に対して 𝒰n∩𝔉≠∅ であるならば， ⋂F∈𝔉CLX⁢(F)≠∅ が成り立つ ときにいう．

定理 6.

X を完全正則空間とする． このとき以下の条件は同値である．

  1. (1)

    X はその任意のコンパクト化の中で Gδ集合になっている．

  2. (2)

    X はある コンパクト化の中で Gδ 集合になっている．

  3. (3)

    X は完備列を持つ．

Kを Xのコンパクト化で X が K の中で Gδ 集合になっているものとしよう． 今から X の完備列を構成する． 空間Xは K のGδ 集合なので ある Kの開集合の可算列 {On} が存在して K=⋂n∈ℤ≥0On となる． ここで各n∈ℤ≥0 とx∈X について Ux,nを Kの開集合であって x∈Ux,nであり CLK⁢(Ux,n)⊂On となるものとする． そして 各 n∈ℤ≥0 について 𝒰n={Ux,n∩X}x∈X と定義すると これはXの被覆になっている． 今から 𝐔={𝒰n}n∈ℤ≥0 が完備列であることを証明しよう． 任意にX上のフィルター 𝔉 を取り， 任意のn∈ℤ≥0 について 𝒰n∩𝔉≠∅ と仮定する． このとき 𝔊={CLK⁢(F)∣F∈𝔉} を考えるとこれは 𝔊上のフィルター基底になっており， 特に有限交差性を持つので ⋂F∈𝔉CLK⁢(F)≠∅ である． さて， 𝒰n∩𝔉≠∅ なのであるUxn,n∈𝒰n が存在して Uxn,n∈𝔉 となる． 特に

⋂F∈𝔉CLK⁢(F)⊂⋂n∈ℤ≥0CLK⁢(Uxn,n)

⋂F∈𝔉CLK⁢(F)⊂⋂n∈ℤ≥0CLK⁢(Uxn,n)⊂⋂n∈ℤ≥0On=X

⋂F∈𝔉CLK⁢(F)=⋂F∈𝔉CLX⁢(F)

であり， この交わりは空ではないので 𝐔 が完備列であることがわかった．

Xの任意のコンパクト化を Kとする． 今から Xが Kの中で Gδ であることを示す． 空間 X の完備列を 𝐔={𝒰n}n∈ℤ≥0 とし 𝒰n={Ui,n}i∈In と表示しよう． そして各 n∈ℤ≥0 と i∈In について Vi,n∩X=Ui,n となるような Kの開集合 Vi,nをとる． ここで

On=⋃i∈InVi,n

と定義する． すると X⊂⋂n∈ℤ≥0On は定義からすぐに従う． 今から X⊃⋂n∈ℤ≥0On を示す． 点 x∈⋂n∈ℤ≥0On を任意にとる． そして 𝔑 を x の K における 近傍系とする． さらに 𝔉={N∩X∣N∈𝔑} と定義する． 空間 X は K の中で稠密なので 𝔑 が開集合を基底とするフィルターとなることから 𝔉 は Xの上の フィルター基底となる． 任意に n∈ℤ≥0 を与える． このとき x∈Onであるから ある i∈Inが存在sて x∈Vi,n となる． つまり Vi,n は xの近傍になっている． このとき Vi,nと 𝔉 の定義から Ui,n=Vi,n∩X∈𝔉 となる． つまり 𝒰n∩𝔉≠∅ である． ここで 𝐔 が完備列であること を用いると ⋂F∈𝔉CLX⁢(F)≠∅ である． さてここでKが正則であることとℱ の定義及びXがK の中で稠密であることから

⋂F∈𝔉CLK⁢(F)={x}

である．一般にCLX⁢(F)⊂CLK⁢(F) であることから

⋂F∈𝔉CLX⁢(F)⊂⋂F∈𝔉CLK⁢(F)={x}

であり ⋂F∈𝔉CLX⁢(F)≠∅ であることから

⋂F∈𝔉CLX⁢(F)={x}

でなければならない． 集合 ⋂F∈𝔉CLX⁢(F) は X の部分集合なので x∈X が従う． 以上から X=⋂n∈ℤ≥0On なので X は K の Gδ 集合である．

定義 7.

完全正則空間 X が チェック完備 (Čech完備, Čech complete) であるとは 定理6 の三つの条件のうちどれかひとつ (結果として全て)を満たすときに いう． 一般的には Xのストーンチェックコンパクト化 β⁢X の中で Gδ であると定義する場合が多いような気がする． Čechというのは数学者の名前である．

定理 8.

チェック完備な完全正則空間は ベールである．

証明.

定理 2 と 補題 3， そして 定理 6 からわかる． ∎

定理 9.

完備距離化可能空間 X はチェック完備である．

証明.

空間X 上の距離関数 d であって 完備であり なおかつ Xと同じ位相を誘導するものを固定する． このとき 各 n∈ℤ≥0 について 𝒰n を (dに関して) 直径が2−n以下の 開集合全体とする． このとき 𝐔={𝒰n}n∈ℤ≥0 が完備列になるのは， 完備距離空間の区間縮小法からわかる． ∎

定理 10.

局所コンパクトハウスドルフ空間 X はチェック完備である．

証明.

𝒰0 を Xの 相対コンパクトな開集合全体とし n≥1のとき 𝒰n はなんでもいい． 𝒰n=𝒰0 でもいいし 𝒰n={X} でもいい． とにかくこのとき 𝐔={𝒰n}n∈ℤ≥0 が完備列であることを示そう． フィルター 𝔉 が𝔉∩𝒰0≠∅ とすると ある O∈𝒰0 が存在して O∈𝔉 である． ここで フィルター基底 𝔊={CLX⁢(F∩O)∣F∈𝔉} を考えると 𝔊 は コンパクト集合 CLX⁢(O)上の の有限交差性を持つ集合族になる． よって

⋂𝔊≠∅

となる． さて 定義から

⋂𝔊⊂⋂F∈𝔉CLX⁢(F)

なので 特に ⋂F∈𝔉CLX⁢(F) がわかる． つまり 𝐔 は完備列である． ∎

注意.

実際はより強く， 局所コンパクトハウスドルフ空間 Xは そのコンパクト化K の中で 開集合になることがわかる． 実際点 x∈X に対して X の中での相対コンパクトな開近傍 Vを取り， Uを U∩X=V となるような Kの近傍とする． このとき CLX⁢(V) はコンパクトで Kはハウスドルフであるから CLX⁢(V)=CLK⁢(V) が成り立つ． Xは K の中で稠密であるから， 特に U は V の中で稠密である． つまり CLK⁢(U)=CLK⁢(V) である． よって CLK⁢(V)=CLX⁢(V)⊂X であるからさらに U⊂CLK⁢(U)⊂X が成り立つ． ゆえに U=Vである． つまり 任意のx∈X はK の中で X の 内点になっている ので X はK の 中で開集合である． 参考文献 [電波通信2] も参照のこと．

系 11 (ベールの範疇定理).

完備距離化可能空間 と 局所コンパクトハウスドルフ空間 は ベール空間である．

証明.

定理 8 と 定理9と 10 から 従う． 本当は完全正則空間には コンパクト化が少なくとも一つ存在するという議論が必要だが 省略する．ストーンチェックコンパクト化などがある． ∎

3 おまけ

以下の定理を 完備列を用いて証明する．

定理 12.

チェック完備な 完全正則空間 はベール空間である．

証明.

Xの完備列を 𝐔={𝒰n}n∈ℤ≥0 とし 𝒰n={Ui}i∈In と表すことにする． そして Xの稠密な開集合の可算族 を {Gn}n∈ℤ≥0 とする． さらに Xの空ではない開集合O を任意に与える． このとき帰納的に Pnを 以下のように定義する． n=0のときは適当に Ui0,0∩G0∩O≠∅ となる Ui0,0∈𝒰0 をとって Xの正規性を使って CL⁢(P0)⊂Ui0,0∩G0∩O となる開集合P0 とする． nまでPnが定義されたとき Pn+1 は適当に Uin+1,n+1∩Gn+1∩Pn≠∅ となる Uin+1,n+1∈𝒰n+1 をとる．このような Uin+1,n+1が取れるのは 𝒰n+1が開被覆であり Gn+1の稠密性から Gn+1∩Pn≠∅ となるからである． そして X の正則性を使って 適当に CL⁢(Pn+1)⊂Uin+1,n+1∩Gn+1∩Pn となる開集合として選ぶ． このとき{Pn}n∈ℤ≥0は有限交差族であり， これから生成されるフィルターは 任意のnについて 𝒰n∩𝔉≠∅ となる． よって 𝐔 が完備列であることから ⋂F∈𝔉CL⁢(F)≠∅ である． つまりこの交わりから 点p をとると p∈Pnなので p∈O でなおかつ p∈Gn でもある． よって O と ⋂nGn は交わりをもつ． つまり ⋂nGn は X の中で稠密である． このことから X がベール空間であることが従う． ∎

チェック完備性が完全写像で保たれることも証明しておこう．

定理 13.

X, Y を完全正則写像とし， f:X→Y を完全写像とする． このとき X がチェック完備ならば Y もそうである．

証明.

この文書では写像f の小像を f? とかく． つまり A⊂X について f?⁢(A)=Y∖f⁢(X∖A) である．

今Xの完備列を 𝐔={𝒰n}n∈ℤ≥0 とし， 𝒰n={Ui,n}i∈In と表示しよう． このとき 𝒪n という記号で 𝒰n の有限部分族の和集合からなる族とする． つまり 𝒪n の元 O は 𝒰n の有限個の元U1,…⁢Um を用いて O=⋃i=1mUi と表すことができる． 次に各 n∈ℤ≥0 について 𝒱n={f?⁢(O)∣O∈𝒪n} と定義する． このとき fが完全写像であることと 𝒪n の定義から 各 𝒱n は Yの 開被覆になっている．

今から 𝐕={𝒰n}n∈ℤ≥0 が Yの 完備列になっていることを示そう． 𝔉 を Yのフィルターであって 各 n∈ℤ≥0 について 𝒱n∩𝔉≠∅ となるものとする． このとき 𝔊={f−1⁢(F)∣F∈𝔉} と定義すると 𝔊 はXの上のフィルターであり， 𝒪n∩𝔊≠∅ を満たす． ここでさらに𝔄 を𝔊⊂𝔄 を満たすような極大フィルターとする． このとき𝔄 が極大であることと 𝒪n の定義から 𝒰n∩𝔄≠∅ となる(この部分がこの証明のポイントである，𝒰nの元の小像全体は 被覆とは限らないがfによる点の逆像がコンパクトであることを用いると 𝒰nの元の有限和集合の族𝒪nの元の小像全体𝒱n がYの被覆になることがわかる， ここで有限和集合をとっているが極大フィルターをとることで埋め合わせをしている，一般に極大フィルター𝔄について A∪B∈𝔄 ならばAかBの少なくとも一つは 𝔄に属するのである)．

よって𝐔 が完備列であることから

⋂A∈𝔄CLX⁢(A)≠∅

である． ここで 𝔊⊂𝔄 なので

⋂A∈𝔄CLX⁢(A)⊂⋂G∈𝔊CLX⁢(G)

が成り立つ． 特に

⋂G∈𝔊CLX⁢(G)≠∅

である． ここでfは連続写像なので任意のA⊂X について f⁢(CLX⁢(A))⊂CLY⁢(f⁢(A)) が成り立つ． よって 𝔊 の定義から

f⁢(⋂G∈𝔊CLX⁢(G))⊂⋂G∈𝔊CLY⁢(f⁢(G))=⋂F∈𝔉CLY⁢(F)

なので， ⋂G∈𝔊CLX⁢(G)≠∅ から ⋂F∈𝔉CLY⁢(F)≠∅ となる． これで 𝐕 が完備列であることがわかった． ∎
