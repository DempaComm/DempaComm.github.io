二次元以上の球面の基本群：全射を回避する話

電波通信 ナンブ　キトラ
HTML変換日：2026年7月26日

1 イントロ

この文章では𝕊n でn次元球面を表すことにする． この文章では次元が2以上の 球面の基本群が自明というやつの面白いところだけ紹介する． つまり次の定理を紹介する．

定理 1.

n∈ℤ≥2とする． このとき 任意の連続写像c:𝕊1→𝕊n は全射ではない連続写像c′:𝕊1→𝕊nにホモトピックである． さらに基点を与えたときには基点を動かさずにこのようなc′(と基点を動かさないホモトピー)を見つけることができる．

この定理を用いると，𝕊n からc′の像に入っていない点xについて 𝕊n∖{x}がℝnに同相であるということと，ℝnが可縮であるからc′が一点に ホモトピックであることがわかり，π1⁢(𝕊n)が自明であること がわかる． どんなn∈ℤ≥2についても連続全射𝕊1→𝕊nはつねに存在するので， 基本群 π1⁢(𝕊n)の同定にはこのような 空間充填曲線を考える必要が付きまとう． この種の曲線の構成は数学書[1]を読むといい． そういえばこういう全射を回避している議論をあんまり見たことないので書いてみた．このことはおそらくこの文書の筆者が代トポの本をちゃんと読んでないことが原因だと思われる．

2 証明その１

定理1の証明をする． まず最初に位相的な証明を紹介する． 面倒なので定理環境使ってないけど許して． この定理の証明は 論文 [8] のアイデアによっている． この論文 [8] 自体はDixon[7] による コーシーの積分定理の簡単な証明の補足である． 論文 [8] の議論の中で， 与えられた閉曲線 γ 上の点 z0∈γ について， 曲線 γ を，考えている積分の値が変わらない程度に， 尚且つ z0 を通らない曲線 γ′ にちょっと修正する議論を参考にしている． この話ははてなブログ電波通信の記事 [5] でも紹介したことがあるので， それを覚えていたので思いついた．

それはさておき証明に入る． 最初に注意するが， 写像 c:𝕊1→𝕊n は全射と仮定しても良い． 全射ではない場合にはそれ自体を c′ として取れるからである．

次に 𝕊n を ℝn+1 の原点を中心とする半径 1 の 球面だとカノニカルにみなす． そして 𝕊n にはℝn+1から誘導される ユークリッド距離 d を与えることにする． 今からは 𝕊1 を[0,1] の 0 と 1 を同一視した空間とみなす．

さて 𝕊n の異なる2点 p,q をなんでもいいので取る． 今から p を含まないように c をホモトピーで変形する． 基点がある場合には q がそれであるように取ることにしよう． さらに c⁢(0)=qと仮定する．このようにしても一般性を失わない． 基点がある場合には 𝕊1 の基点は 0としよう． そして ϵ∈(0,∞) を適当に固定して 距離dによる p を中心とした 半径ϵの 閉球 B⁢(p,ϵ) を考える． ここで ϵ∈(0,∞) を十分小さく取って q∉B⁢(p,ϵ) であり， さらに B⁢(p,ϵ) は n 次元閉球体 Dn と 同相であるとしても良い． 例えば pは北極点になっているとして， B⁢(p,ϵ)が𝕊n の上半球に含まれているとしてもよく， このとき z座標を0にする射影 がB⁢(p,ϵ)と Dnの同相を与える． 実は上のセッティングでさらに pとqを北極と南極として取ったときには， ϵは2 より真に 小さければ今から行う議論は 可能であることがわかったりする． まあ細かい話は置いといて， とにかく小さく取れば良いと思う．

次に A=c−1⁢(p) とする． つまり c によって p に映るような元全体が A である． ここで p≠q であり， c⁢(0)=q なので 0∉A で尚且つ 1∉A に注意しよう． すると十分小さい η∈(0,∞) を取って A⊂(η,1−η) でありさらに c−1⁢(B⁢(p,ϵ))⊂(η,1−η) とできる． これはq∉B⁢(p,ϵ) だからである． またこのとき c⁢(η)∉B⁢(p,ϵ) かつ c⁢(1−η)∉B⁢(p,ϵ) に注意しよう． ここからしばらくは， 写像 c は ℝ の部分集合 [η,1−η] の上で考えて， この区間 [η,1−η] には一次元ユークリッド距離 E が入っているとする．

このとき c:[η,1−η]→𝕊n はコンパクト空間からの連続写像なので， 一様連続である． よって先に与えた ϵ∈(0,∞) に対して δ∈(0,∞) が存在して， E⁢(x,y)<δ となる任意 のx,y∈[η,1−η]について 常に d⁢(c⁢(x),c⁢(y))<ϵとなる． 対偶をとると， 任意の x,y∈[η,1−η] が d⁢(c⁢(x),c⁢(y))≥ϵ満たす ならば常に E⁢(x,y)≥δ を満たす． 今からこのような δ を一つ固定して 話を進める．

さて逆像 c−1⁢(B⁢(p,ϵ)) の連結成分 I であって I∩A≠∅ となるものについて考える． このとき 任意の x∈I∩A は I の内点であり， さらに (x−δ,x+δ)⊂I となる． 今からこれを示そう． 点 x∈A∩I に対して ax=sup{w∈[0,1]∣w<x,d⁢(c⁢(w),c⁢(x))=ϵ} と定義する． 中間値の定理， というか連結空間の連続像が連結であることから， この右辺の集合が空でないということがわかる． 細かい話は省略する． さらに， 再び中間値の定理(連結空間の連続像が連結)から， sup で定義された ax は c⁢([ax,x])⊂B⁢(p,ϵ) を満たす． 以上から c⁢([ax,x])⊂B⁢(p,ϵ) かつd⁢(c⁢(ax),c⁢(x))=ϵ となることがわかる． 同様にしてbxを bx=inf{w∈[0,1]∣x<w,d⁢(c⁢(x),c⁢(w))=ϵ} と定義すると， c⁢([x,bx])⊂B⁢(p,ϵ) かつd⁢(c⁢(x),c⁢(bx))=ϵ となる． よってx∈(ax,bx)⊂I なのでIはxを内点にもつ． 先の一様連続性の議論と d⁢(c⁢(ax),c⁢(x))=ϵ からE⁢(ax,x)≥δ がわかるので， (x−δ,x+δ)⊂I がわかる．

ここでc−1⁢(B⁢(p,ϵ)) の連結成分で， 集合 A と交わりを持つもの全体 {Ik}k∈K を考える． ここで添字は単射であるようにとる． するとこれらは c−1⁢(B⁢(p,ϵ)) の連結成分であるから k≠k′ ならば Ik∩Ik′=∅ である． このとき上で行った議論から， 各Ik は半径δの開球を含む． 空間 [η,1−η] はコンパクトなので そのδ-net は常に有限でなければならないので Kは有限集合でなければならない

ここで注意： 集合 A は一般的に有限集合ではない． 写像 c は一般に p を無限回通過するが， pを通過してさらに p からの 距離がちょうど ϵ になるような点から始まって終わるような区間の数が有限個ということが上で証明したことである． 上の議論で定義した ax と bx について， x,y∈A が x≠y だとしても ax=ay かつ bx=by となることがありうる． 写像 c がある区間上で定数 p を取り続ける状況を考えると， このような事情は分かり易いと思う．

さて，各 Ik は ℝ の連結部分集合でもあり， さらに内点を持つので {Ik}k∈K は {[ai,bi]}i=1m と書くことができる． ここで a1<b1<a2<b2⁢⋯<am<bm とする．

いまから d⁢(c⁢(ai),p)=ϵ を示そう． 背理法で示す． もしも d⁢(c⁢(ai),p)<ϵ ならば， 写像 c の連続性から ai を含む開区間 (α,β) で c⁢((α,β))が pを中心とする 半径 ϵ 開球 に含まれるものが存在する． この議論をするとき c⁢(η)∉B⁢(p,ϵ) かつ c⁢(1−η)∉B⁢(p,ϵ) であることから (α,β)⊂(η,1−η) と取れたりして区間の端っこで開集合が半開区間の形になるとかそういうのを考えずに済む． さて， このとき， [ai,bi]よりも真に大きい集合 [α,bi] もc−1⁢(B⁢(p,ϵ))の連結成分となるが， これは[ai,bi] が c−1⁢(B⁢(p,ϵ)) の連結成分であるということに反する (連結成分の定義を思い出して欲しいのだが，極大な連結部分集合で定義されるのだ)． 同様に d⁢(p,c⁢(bi))=ϵ がわかる．

ここで B⁢(p,ϵ) と n 次元閉球体 Dn を同一視する． 上の議論から Dn の境界 𝕊n−1 について c⁢(ai),c⁢(bi)∈𝕊n−1 となることに注意しよう． そして各 i∈{1,…,m} について c⁢(ai) と c⁢(bi) を結ぶ Dn の境界 𝕊n−1 上の曲線 wi:[ai,bi]→𝕊n−1 を考える． そして ホモトピー H:𝕊1×[0,1]→𝕊n を[ai,bi]×[0,1] 上では H⁢(x,t)=(1−t)⁢c⁢(x)+t⁢wi⁢(x) とし， それ以外では常に H⁢(x,t)=c⁢(x) として定義する． そして c′=H⁢(x,1) と定義すると， 写像c′ の像は p を含まない． p を含む曲線分は H でちゃんと動かしてB⁢(p,ϵ)の境界になっているからである．

追記１： 精密にするならば B⁢(p,ϵ) と Dn の同相写像で写して 線分で繋いでさらに B⁢(p,ϵ) に引き戻す操作 をする必要があるが，今このように注意すれば十分なので省略する．

追記２： さらに精密には H の連続性を示すときに任意の t∈[0,1] について H⁢(ai,t)=c⁢(ai)=wi⁢(ai) と H⁢(bi,t)=c⁢(bi)=wi⁢(bi) であるから， 写像がいい感じに張り合わされて 連続性がわかるという議論が必要である． 一般に位相空間 X と Y， そして X の有限の閉集合族 {Ai}i=1mと 連続写像 fi:Ai→Y が Ai∩Aj 上で fi=fj を満たすならば f:X→Y はwell-definedに貼り合わされるし， 連続でもあることが証明できる． これは連続写像の定義に閉集合の逆像が閉集合というやつと， 今考えている族が有限であることからすぐにわかる．

以上で定理1の証明が終わる．□

3 証明その２

次に 滑らかな写像を使った証明を紹介する． この世の中， 多様体を使う人がなんか多いので， そういう人のために そのそれっぽい証明も紹介する．

最初に注意するが， 写像 c:𝕊1→𝕊n は全射と仮定しても良い． 全射ではない場合にはそれ自体を c′ として取れるからである．

今から c:𝕊1→𝕊n に対して滑らかな写像 F:𝕊1→𝕊n が存在して c は Fにホモトピックであることを証明する．

いま 𝕊n を ℝn+1 の点 (x1,…,xn+1)で x12+⋯+xn+12=1 を満たすもの全体の集合とカノニカルに同一視する．

上でいう滑らかな写像の意味 は多様体の間の C∞級写像ということだが， 上のようなカノニカルな同一視をした場合には， 写像 f:𝕊1→𝕊n が滑らか であるとは， これを 𝕊1 から ℝn+1 への写像とみなして， さらに 巻きつき写像 E:ℝ→𝕊1;t→(cos⁡(t),sin⁡(t)) を考えたときの， 合成写像 f∘E:ℝ→ℝn+1 が普通の意味で C∞ 級写像という意味でも同じことである．

さて 写像 w=c∘E:ℝ→𝕊n↪ℝn+1 を w⁢(t)=(w1⁢(t),…,wn+1⁢(t))∈ℝn+1 と表示する． そして ϵ∈(0,∞) を十分小さくとる． 今回は大体 ϵ=10−100 くらいで十分じゃないかな．

このとき各 i∈{1,…,n+1} について， wi は周期 2⁢π の周期関数になっていることに注意しよう． すると三角多項式による近似定理だとか軟化子だとか， ストーンワイエルストラスとか，なんでもいいのでそういう類のやつを使うと， 周期 2⁢π の滑らかな関数 fi が存在して 任意の t∈ℝ について |wi⁢(t)−fi⁢(t)|<ϵ となる．

ここで基点をつけて考えている場合には， 0∈[0,2⁢π]↭𝕊1 を基点としているとして (ここで [0,2⁢π]↭𝕊1 は 0 と 2⁢π を同一視して 𝕊1 とみなしているという程度の意味なので深く考えなくてよい)， 適当に並行移動したりして wi⁢(0)=fi⁢(0) となるようにできる． ただし近似の評価が |wi⁢(t)−fi⁢(t)|<2⁢ϵ というふうに修正しないといけないが， ϵを小さく取っているので， これから行う議論にはなんの影響もない．

そして F:𝕊1→ℝn+1 を f⁢(x)=(f1⁢(x),…,fn+1⁢(x)) と定義すると， ϵ が十分小さいので 0∉f⁢(𝕊1) である． ここでホモトピー h:𝕊1→ℝn+1∖{0} を h⁢(x,t)=(1−t)⁢w⁢(x)+t⁢f⁢(x) と定義する． すると h は w と f を結ぶホモトピーであり， f は滑らかである． ここで注意なのだが， h⁢(𝕊1×{t})⊂𝕊n とは限らない! そこでひと工夫する． まず， 任意の(x,t)∈𝕊1について |w⁢(x)−h⁢(x,t)|<ϵ (基点考えているときは<2⁢ϵ) なので， 任意の t∈[0,1] について 0∉h⁢(𝕊1×{t}) に注意しよう． さらに写像 p:ℝn+1∖{0}→𝕊nを

p⁢(x1,…,xn+1)=1x12+…⁢xn+12⁢(x1,…,xn+1)

と定義する． するとこの写像 pは滑らかな写像であることに注意しよう． このとき x∈𝕊n について p⁢(x)=x にも注意しよう． つまりpは滑らかな写像であってさらに ℝn+1 から 𝕊n へのレトラクションであるということである．

そしてホモトピー H:𝕊1×[0,1]→𝕊nを H=p∘h と定義する． すると H⁢(x,0)=p⁢(c⁢(x))=c⁢(x) である． また，fとpは滑らかなので これらの合成である H⁢(x,1)=p∘f⁢(x) は 𝕊1 から 𝕊nへの 滑らかな写像である． よって F=p∘f と定義すれば cは 滑らかな写像 F:𝕊1→𝕊n にホモトピックである．

次に F が全射ではないことを証明しよう． これはある程度簡単である． 写像 Fが滑らか，特に C1級 であることとサードの定理から F の微分がフルランクではないような点全体 C⊂𝕊1 について F⁢(C) は零集合である． ここで 𝕊1 は一次元で 𝕊n は n 次元なので至る所でフルランクではない． つまり C=𝕊1 であり F⁢(𝕊1) が零集合ということなので F⁢(𝕊1) に含まれない点x∈𝕊n が存在する． よってFは全射ではなく， c′=F とすれば定理 1 の証明は終わる．

追記１： (滑らかな場合の)サードの定理の証明などは [2]や[3]を参照のこと． 一応，はてなブログ電波通信の記事 [6]にも紹介されている． さてここでサードの定理を用いたが， 定義域の次元が行き先の次元より真に小さい場合には， サードの定理は意外と簡単に証明できることを注意しておく．なんとなれば， 今ここで 𝕊1 と 𝕊n にはユークリッド空間から誘導される距離を導入する． このとき F は C1 級なので， これらの距離について 局所リプシッツである． 空間 𝕊1 はリンデレフなので可算個の開集合 {Ui}i∈ℤ≥0 が存在して F は Ui 上でリプシッツである． よって各 i について F⁢(Ui) のハウスドルフ次元は 1 より小さい． よってこれら可算個の和集合 ⋃iF⁢(Ui)=F⁢(𝕊1) のハウスドルフ次元も高々 1 である． さらに上で導入した距離について 𝕊n のハウスドルフ次元は n なので F⁢(𝕊1) は 𝕊n の n 次元ハウスドルフ測度について零集合であるから F⁢(𝕊1) は全射ではない． この証明でユークリッド距離を導入しているのはそこまで自由に動かせない． 可微分写像はユークリッド距離を相性がいいんだと思うと良いと思う．

実はサードの定理に出てくる 「零集合」 というのは n 次元ハウスドルフ測度による零集合と一致するのである． というか，そこから逆算して測度を導入せずに「零集合」の概念を導入しているんだと思う． さらにいうとそれは， その多様体の上の どんなリーマン計量によって誘導されるリーマン体積による測度による零集合とも一致する． これらの話は多様体が局所的に通常のユークリッド空間とリプシッツであるとか， C1 級写像は全て局所リプシッツとか， そういう話から直ちにわかることである． 上の証明は 「ハウスドルフ次元」というわけわからんものを いきなり使っているが， 証明をよく見ると通常のサードの定理(定義域の次元が低い場合)の証明と同じことをやっていることがわかる．

まあわかんなくても， 見る人が見ればそうなっているんだなって思ってもらうといいんじゃないかなと思う． ハウスドルフ次元などについては [4]などを参照のこと．

追記２： 上の証明の議論で レトラクション p:ℝn+1∖{0}→𝕊n を用いたが， 多様体論的にはこれは多分 𝕊n の管状近傍を使って写像の近似をしたというふうに まとめることができるんじゃないかと思う．

追記３： 上のサードの定理の議論から， cと 滑らかな写像をホモトピーで 繋ぐのではなく， 局所リプシッツな写像や， 区分的C1関数に結べば 定理 1 は証明できることがわかる． でも滑らかな写像で近似するみたいなそういう話題は， 滑らかな写像の方が豊富だと思うので， 定理を証明するには強すぎる性質だが， ありがたく使わせてもらおう． 先駆者に感謝．

追記４：証明の中で近似定理を用いたが， ここでの近似定理は近似をするというよりは， cとホモトピーで結べてさらに0を回避するのを保証する程度の役割しかなく，ϵはそんな小さくとらなくても良い．おそらくϵを1よりも真に小さくすれば どれでも用を成せるだろう．

証明終わり．□

位相的な証明の方が，筆者は好きです．
