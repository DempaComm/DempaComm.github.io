1 基本的な記号と定義

1.1 記号と概念

定義 1.

この文章では写像 f:X→Y によるYの部分集合 Sの逆像 を f←⁢(S) と書くことにする． 普通は f−1⁢(S) と書くところである． ただしXの部分集合A のfによる像はただ単に f⁢(A)と書くことにする． たまに f→⁢(A)って書いたりするよね．

定義 2 (疎な族).

位相空間X の部分集合からなる族 𝒜={Ai}i∈ℤ≥0 が疎(discrete) であるとは X の任意の点 x∈X について その近傍 N が存在して， N が空でない交わりを持つような 𝒜 の元はたかだか一個しかないとき にいう． また 𝒜 がσ疎 (σ-discrete) であるとは ある可算族𝒜n が存在して 𝒜=⋃n∈ℤ≥0𝒜n でありなおかつ 各𝒜n は疎であるときにいう．

定義 3 (局所有限族).

位相空間 X の部分集合族 𝒜={Ai}i∈I が 局所有限 であるとは 任意の x∈X についてある xの近傍 N が存在して Nと交わりを持つような 𝒜 の元が有限個しかない時にいう． つまり集合 {i∈I∣Ai∩N≠∅} が有限集合ということである． またこの文章では 局所有限な族 𝒜 と x∈X について 𝒜の局所有限性を担保するxの近傍V という文言をしばしば用いるがこれは xの近傍V であって 𝒜 の有限個の元としか交わらないもの を指す．

定義 4 (細分).

位相空間 X の部分集合族 𝒜={Ai}i∈I と ℬ={Bt}t∈T について ℬ が 𝒜 の 細分 であるとは 任意のt∈T に対して i∈I が存在して Bt⊂Ai となる時にいう．

定義 5 (パラコンパクト).

位相空間 X が パラコンパクト であるとは X の任意の開被覆 𝒜={Ui}i∈I に対して 𝒜 の細分であるような 局所有限な開被覆 ℬ が存在するときにいう．

定義 6.

位相空間X とその部分集合 Sについて Sの閉包を CL⁢(S) で表す． どの空間の閉包か強調するために CLX⁢(S) 表すときもある．

定義 7 (閉写像).

位相空間X, Y の間の連続写像 f:X→Y が 閉写像 であるとは X の閉集合の f による像が Y の閉集合に常になってることである．

ついでに完全写像も定義する．

定義 8 (完全写像).

位相空間X, Y の間の連続写像 f:X→Y が 完全写像であるとは fが閉写像であり なおかつ 任意のy∈Y について f←⁢(y) がコンパクトである時にいう．

2 正規性

定義 15 (ℵ0-族正規).

位相空間Xが ℵ0-族正規(ℵ0-collectionwise normal)であるとは その任意の閉集合からなる疎な可算族 𝒜={Ai}i∈ℤ≥0 に対して開集合からなる疎な可算族 {Ui}i∈ℤ≥0 が存在して，任意の i∈ℤ≥0について Ai⊂Ui を満たす時にいう．

一般に族正規というのもあるがそれは族の濃度に制限を加えないものである． さて上で仰々しく定義したこの概念は実は ただの正規性と同値になってしまう．

筆者がこのことを知ったのは [Dan Ma] が最初だと思う． これを最初に証明した原論文 はおそらく [13]だと思われる．

定理 16.

位相空間X が正規であることと， ℵ0-族正規であることは同値である．

証明.

ℵ0-族正規ならば正規であるから Xが正規のときにこれが ℵ0-族正規であることを証明すれば十分である． 可算族 𝒜={Ai}i∈ℤ≥0 は疎であり閉集合からなるとする． 各i∈ℤ≥0 に対して

Bi=X∖(⋃j∈ℤ≥0,j≠iAj)

と定義すると 𝒜 が閉集合からなる 疎な族であることから 各 Bi は開集合である． さらに各 i∈ℤ≥0 について

Ai⊂Bi

となることに注意しよう． このとき Xの正規性から， 各iについて 開集合 Pi が存在して

Ai⊂Pi⊂CL⁢(Pi)⊂Bi

となる． ここで CL⁢(Pi)⊂Bi ということと， Bi の定義から， もしも j∈ℤ≥0 が j≠iを満たすならば

Aj∩CL⁢(Pi)=∅

であることにも注意しよう．

さて今， 開集合 Qi を

Qi=Pi∖(⋃j≤iCL⁢(Pj))

と定義する． このとき各 Qi は開集合であるし，

Qi⊂Pi

である． そして 上の注意から

Ai⊂Qi

でもある． 今から {Qi} が互いに素であることを証明しよう． i≠k と仮定する． このとき i<k と仮定しても良い． このとき Qi⊂Pi と Qkの定義から Qi∩Qk≠∅ となる． ここでさらに X の正規性を用いて

⋃i∈ℤ≥0Ai⊂W⊂CL⁢(W)⊂⋃i∈ℤ≥0Qi

となる開集合 W をとる． ここで 𝒜 が疎であることを使って ⋃i∈ℤ≥0Ai が閉集合であるということを用いていることに注意しよう． そして 各 i∈ℤ≥0 について

Ui=W∩Qi

と定義する． 今から {Ui}i∈ℤ≥0 が疎な族 であることを証明しよう． 点 x∈X を任意にとる． 場合分けを行う．

場合分けその1. x∈Qi となる i∈ℤ≥0 が存在する場合． このとき 族{Qi}i∈ℤ≥0 が互いに素であることから 族 {Ui}も互いに素である． よって Qi は Uiのみとしか交わらない．

場合分けその２． どんな i∈ℤ≥0 についても x∉Qi であるとき． このとき x∉⋃i∈ℤ≥0Qi なので， 特に x∉CL⁢(W) である．よって開集合 X∖CL⁢(W) は x の近傍であると同時に いかなる Uiとも交わりを持たない．

以上のことから {Ui}i∈ℤ≥0 が疎な族であることがわかった． 𝒜 は任意であったので， 結局 Xが ℵ0-族正規であることが証明された． ∎

以下の命題は [電波通信4] などを参照のこと．

事実 17.

位相空間 X が正規であることと以下の 命題は同値である． Xの 開集合からなる任意の局所有限被覆 {Ui}i∈I に対して 開被覆{Vi}i∈I が存在して，任意のi∈I について CL⁢(Vi)⊂Ui が成り立つ．

3 可算コンパクト

このセクションは [電波通信1] の引き写しである．

定義 18 (可算コンパクト).

位相空間 X が 可算コンパクト であるとは， その任意の可算開被覆について 有限な部分被覆を選べるときにいう．

定義 19 (完全集積点).

位相空間 Xの 部分集合 Aについて， x∈X が A の 完全集積点 であるとは， x の任意の開近傍 U について

card⁢(A)=card⁢(U∩A)

となるときにいう．

定理 20.

位相空間Xについて以下は同値である．

  1. (1)

    X は可算コンパクトである．

  2. (2)

    X の任意の可算部分集合 A に完全集積点が存在する．

  3. (3)

    X の任意の無限部分集合 A について点 a∈X が存在して a の任意の近傍 Nについて

    card⁢(A∩N)≥ℵ0

    が満たされる．

証明.

(2) と (3)が同値であることはよくわかる． (1) と (2)が同値であることを示そう． 対偶を証明する．

[¬(2)⟹¬(1)の証明]

¬(2)より， 完全集積点を持たない可算無限集合 A が存在する． 完全集積点を持たないので各点 x∈X について x の近傍 Ux が存在して card⁢(Ux∩A)<ℵ0 となる． さて A の有限部分集合 S について

OS=⋃{Ux∣Ux∩A=S}

と定義しよう． A の有限部分集合全体 ℱ は可算集合であるから， {OS}S∈ℱ は可算な族であり， X の開被覆である． しかし構成の仕方からわかるように {OS}S∈ℱ の有限部分被覆 𝒰 の和集合 ⋃𝒰 と A について (⋃𝒰)∩A は有限集合である． よって X≠⋃𝒰 が成り立つ． つまり {OS}S∈ℱ は有限部分被覆を持たない X の可算開被覆である． ゆえに Xは可算コンパクトでない．

[¬(2)⟹¬(1)終わり]

[¬(1)⟹¬(2)の証明]

X は可算コンパクトでないから有限部分被覆を持たない可算開被覆 𝒰={Ui}i∈ℕが存在する． そこで {ai}i∈ℕを

an∉⋃i=0nUi

でかつ n≠m⟹an≠am となるように選ぶ （これはちゃんと実行できる）． そして A={an}n∈ℕ とすると A は可算無限集合である． これが完全集積点を持たないことを示そう． 任意の x∈X について x∈Um となる 𝒰 の元をとると， 構成の仕方から Um は高々 m+1 個の A の元としか交わらない． よって x は任意であったから A は完全集積点を持たない Xの可算部分集合である．

[¬(1)⟹¬(2)終わり] ∎

系 21.

T1 位相空間 X が 可算コンパクトでないとすると， X の閉集合であるような可算離散空間 A={pi}i∈ℤ≥0 が存在する． 特にこのような {{pi}}i∈ℤ≥0 は疎な族でもある．

証明.

今 X は可算コンパクトではないので 定理 20 から 完全集積点を持たないような可算部分集合 A={pi}i∈ℤ≥0 が存在する． 今から {{pi}}i∈ℤ≥0 が疎であることを証明しよう． どの点 x∈X も A の完全集積点ではないので x の近傍 M が存在して card⁢(A∩M)<ℵ0 となる． 今 X は T1 と仮定しているので， 有限集合 S=(A∩M)∖{x} は閉集合である． よって N=M∖S とすればこれは card⁢(A∩N)≤1 を満たす． よって {pi}i∈ℤ≥0 は疎な族である． このことから A が離散集合で閉集合であることもわかる． ∎

位相空間 X, Y の間の連続写像 f:X→Y について以下は同値

  1. (1)

    写像fは閉写像である．

  2. (2)

  3. (3)

    任意の S⊂Y と f←⁢(S) の任意の近傍 U について S の近傍 V が存在して

    が成り立つ．

  4. (4)

    任意の y∈Y と f←⁢(y) の任意の近傍 U について y の近傍 V が存在して

5 パラコンパクト性

定理 29.

Xを正則ハウスドルフ空間とする． このときX がパラコンパクトであることと Xの任意の開被覆には その細分であるような Xの閉集合からなる被覆が存在することが 同値である．

証明.

まず最初に X がパラコンパクトであると仮定する． そして 𝒜={Ui}i∈I をXの任意の開被覆とする． このとき 𝒜 の細分であるような開集合からなる 局所有限な被覆 ℬ={Vt}t∈T が存在する． パラコンパクトハウスドルフ空間は 正規なので X は正規である． よって開集合からなる 被覆𝒞={Ot}t∈T であってCL⁢(Ct)⊂Vt となるものが存在する (事実 17)． ここで 𝒟={CL⁢(Ct)}t∈T とおくとこれは 𝒜 の細分であって閉集合からなる 局所有限な被覆になっている (補題11)． これで前半の証明が終わる．

後半を示そう． つまり X の任意の開被覆には その細分であるような Xの閉集合からなる被覆が存在すると仮定しよう． 今からXがパラコンパクトであることを示す．

W⁢(A)=X∖(⋃l∈R,A∩Dl=∅Ds,l)

と定義する． 族𝒟 の局所有限性から Z0 が有限であることがわかる． さらに Z0の有限性と 𝒟が𝒞 の細分であることから Z1が有限であることがわかる．

今ここで t∈Tは W⁢(Bt)∩W⁢({x})≠∅ を満たすと仮定しよう． この交わりから点 yをとる． 族𝒟 が被覆になっていることから y∈Drとなる r∈R が取れる． さてW⁢({x}) の定義とy∈W⁢({x}) であることから x∈Dr でもある． つまり r∈Z0である． さらに y∈W⁢(Bt) と W⁢(Bt) の定義から Dr∩Bt≠∅ である． ここでr∈Z0 であったから t∈Z1 である． 上で話したことから Z1 は 有限集合であるから W⁢({x}) は有限個の W⁢(Bt)としか交わらないことが従う． よって {W⁢(Bt)}t∈T は局所有限である．

補題 30.

X と Y を位相空間とし， f:X→Y は完全写像とする． そして 𝒜={Ai}i∈I はXの部分集合からなる局所有限な 族とする． このとき Yの開集合からなる被覆 {Ot}t∈T であって， 任意のt∈T について f←⁢(V) は有限個の 𝒜 の元としか交わらないようなものが存在する．

任意に点y∈Yをとる． 集合 f←⁢(y) がコンパクトであることと 補題 13 から f←⁢(y) の近傍 U であって U は 𝒜 の有限個の元としか交わらないものが存在する． 次に 定理 27 の 条件 (4) から yの開近傍 Oy が存在して f←⁢(Oy)⊂U となる． この包含関係から f←⁢(Oy) も 𝒜 の有限個の元としか交わらない． 点y∈Yは任意だったので，これで証明が終わる． ∎

以上のことを用いて パラコンパクト性が完全写像で保たれることを示そう． ただし実際には パラコンパクト性は 閉写像だけでも保たれる (論文 [15]を参照のこと)． 完全写像の場合は少々簡単に証明できるし せっかくなので証明しておく．

定理 31.

Xをパラコンパクトハウスドルフ空間 とし， Yを位相空間で f:X→Y は全射な完全写像とする． このとき Y もパラコンパクトハウスドルフである．

証明.

まず fが閉写像であるから Yは正規ハウスドルフである． よって Yがパラコンパクトである ことを証明すれば良い． Yの任意の開被覆を 𝒜={Ui}i∈I とする． このとき ℬ={f←⁢(Ui)}i∈I はXの 開被覆である． よってX のパラコンパクト性から ℬ の細分であるような閉集合からなる Xの被覆 𝒞={Ct}t∈T が 存在する(定理29)．

このとき 𝒟={f⁢(Ct)}t∈T が 𝒜 の細分であるような閉集合からなる被覆であることを証明しよう．そうすると 再び定理 29 を用いて Y がパラコンパクトであることが従う．

まず ℬ が X の 被覆であることと f が全射であることから 𝒟 が Y の被覆であることはわかる． 写像 f が閉写像なので 𝒟 が閉集合からなることもわかる．

次に 𝒟 が 𝒜 の細分であることを 証明しよう． まず𝒞 はℬ の細分なので 各t∈T について i∈Iが存在して Ct⊂f←⁢(Ui) を満たす． よって f⁢(Ct)⊂Ui である． これで𝒟 が𝒜 の細分であることがわかった．

今から𝒟 が 局所有限であることを 証明しよう． 点x∈Y をとる． すると 補題30 から x の近傍 V が存在して f←⁢(V) は 𝒞 の有限個の元としか交わらない． 開集合f←⁢(V)と 交わる 𝒞の元を Ct1,…,Ctm と 書こう． さて f⁢(Ct)∩V≠∅ であると仮定しよう． すると 命題 22 から f⁢(Ct∩f←⁢(V))=f⁢(Ct)∩V なので 特に f⁢(Ct∩f←⁢(V))≠∅ である． よって Ct∩f←⁢(V)≠∅ が従う． ゆえに， Ct1,…,Ctm の定義から あるk∈{1,…,m}が存在して Ct=Ctkとなる． つまり Vと 交わるような 𝒟 の元は せいぜい f⁢(Ct1),…,f⁢(Ctm) だけである． よって 𝒟 は局所有限である． これで証明が終わる． ∎

パラコンパクト空間 の開被覆には σ疎 な細分が存在することを証明しよう． これは 距離化可能性が 完全写像で保たれるということの証明に用いる． このような性質はstrongly screenable と呼ばれているようで (論文[20]などを参照のこと)， 実際には この性質は，空間の正則性を仮定した上で パラコンパクト性と同値である (論文 [18]などを参照のこと)．

6 完全写像と距離化可能性

以下はBing–長田–Smirnovである． 証明とか原論文 などは [電波通信3] で紹介されていると思う．

事実 34.

正則ハウスドルフ空間 Xに関して， Xが距離化可能であることと Xに σ疎な 開基が存在することは同値である．

今から距離化可能性が 完全像で保たれることを証明しよう． これが 花井–森田・ストーンの定理の中で 一番難しい部分だと思われる．

定理 35.

Xを距離化可能空間とする．そして Y を位相空間とし， 写像 f:X→Y は全射連続でなおかつ完全写像 とする． このとき Y は距離化可能である．

証明.

まずfが閉写像であることから Yが正規ハウスドルフになることに注意しよう． よってYがσ疎な 開基を持つことを示せば良い． また 定理 31 から Yはパラコンパクトであることにも 注意しよう．

Bing–長田–Smirnovの定理 (事実34)を用いて 距離化可能空間 X の σ 疎な開基を ℬ とり， そして ℬ=⋃n∈ℤ≥0ℬn と表示して 各 ℬn は疎であるとする．

自然数の集合 ℤ≥0 の空でない有限集合全体の集合を 𝔉 と書くことにする． このとき𝔉 は可算無限集合であることに注意しよう．

各 S∈𝔉 について ℬS という記号で 族 ⋃i∈Sℬi を表すことにする． 各ℬi が疎で, Sが有限集合であることから ℬS はXの局所有限な族になっている．

さて S∈𝔉 を任意に固定する． 空間X の局所有限 ℬSに 補題 30 を適応すると Yの開被覆 𝒬S であって 任意の O∈𝒬S について f←⁢(O) は ℬS の有限個の元としか交わりを持たない． ここでYはパラコンパクトハウスドルフ空間なので 定理 32 を 𝒬 に適応して これの細分になるような 開被覆 𝒱S であって σ疎な ものが取れる． ここで

𝒱S=⋃n∈ℤ≥0𝒱S,n

と表示して 各 𝒱S,n は疎であるとする． この𝒱Sが𝒬S の細分であることから 各V∈𝒱S について f←⁢(V)は ℬS の有限個の元としか交わらない．

さてここで各 S∈𝔉 と V∈𝒱S に対して 集合

ℭ⁢(V)

を ℬS の元であって f←⁢(V) と交わるもの全体とする． もちろん ℭ⁢(V) は有限集合である． さらに 各V∈𝒱Sに対して 写像

τV:ℭ⁢(V)→ℤ≥0

を 適当になんでもいいので単射な写像としてとり固定する． 単射であればなんでもいい．これは ℭ⁢(V) が有限集合なので可能である． この写像 τV は ℭ⁢(V)の番号付けということである． さらに 各 T∈𝔉 について集合

ℭ⁢(V;T)

を ℭ⁢(V) の元Bであって τV⁢(B)∈T となるもの全体とする． つまり ℭ⁢(V;T) とは ℭ⁢(V) の元であって その番号がTに属しているもの全体ということである．

各 S∈𝔉 と V∈𝒱S, そして T∈𝔉について

W⁢(V,T)=⋃B∈ℭ⁢(V;T)f←⁢(V)∩B

と定義する． これはただ単に ℭ⁢(V;T)の和集合と f←⁢(V)の交わりである． このW⁢(V,T)は開集合であることに注意しよう． そして V∈𝒱S,nについて

O⁢(V,T)=f?⁢(W⁢(V,T))

と定義する． 集合W⁢(V,T)がf←⁢(V) の部分集合であったことから O⁢(V,T)⊂V であることに注意しよう． さらに一般に O⁢(V,T) は空集合になることもありうるが， 別に空集合だとしても以下の議論には差し障りはないので そういうことはあまり気にしないことにする．

各S∈𝔉， n∈ℤ≥0 と T∈𝔉について

𝒞S,n,T={O⁢(V,T)∣V∈𝒱S,n}

と定義する．これは 開集合からなる Y の族である．今から この 𝒞S,n,T が疎であることを確かめよう． まず 任意の Vについて O⁢(V,T)⊂Vである． よって 𝒱S,n が疎であることから 𝒞S,n,Tも 疎な族であることがわかる (補題14)．

ここで

𝒞=⋃S∈𝔉,n∈ℤ≥0,T∈𝔉𝒞S,n,T

と定義する． 上で述べたことから 各 𝒞S,n,T が疎であり， 𝔉とℤ≥0 が可算集合であることから 𝒞 は σ疎である．

今から この 𝒞 が Y の開基に なっていることを証明しよう． 点 y∈Y とYの開集合 Uを任意に取り y∈U を満たしているとしよう． 今からあるC∈𝒞 が存在して y∈C⊂U となることを示そう． まず当たり前だが， y∈Uから f←⁢(y)⊂f←⁢(U) となっている． 今 ℬが開基であることと， f←⁢(y) がコンパクトであることから ある有限集合 Sy∈𝔉と 有限族 ℰ⊂ℬSy が存在して

f←⊂⋃ℰ⊂f←⁢(V)

が成り立つ． ここで以下の話を簡単にするために 任意の B∈ℰについては f←⁢(y)∩B≠∅ となっていると仮定する． お望みであれば，こういうふうになるように ℰ を選び直せる． この時ある ny∈ℤ≥0 と V∈𝒱Sy,ny が存在して y∈Vが成り立つ． すると f←⁢(y)⊂f←⁢(V) であることと， ℰの元はf←⁢(y) と交わるように取っていることから ℰ⊂ℭ⁢(V) がわかる． そして Ty∈𝔉 を Ty={τV⁢(B)∣B∈ℰ} と定義する． 写像τV が単射であることから ℭ⁢(V;Ty)=ℰ がわかる． このとき

W⁢(V,Ty)=f←⁢(V)∩⋃ℰ

である． ゆえに f←⁢(y)⊂⋃ℰ であることと y∈Vであることから

f←⁢(y)⊂W⁢(V,Ty)⊂⋃ℰ⊂f←⁢(U)

である． この包含関係から

y∈O⁢(V,Ty)⊂U

がわかる (定理27の条件(4))． そして集合 O⁢(V,Ty) は 族 𝒞Sy,ny,Ty に属する． なので yとU が任意であったことから 𝒞 が開基であることがわかった．

以上のことと Bing–長田–Smirnov の定理 (事実34) から Yが距離化可能であることが証明された． ∎

7 花井–森田・ストーン

以下では， 位相空間 X の部分集合Aについて その境界を Fr⁢A と書くことにする．

おそらく花井–森田・ストーンの定理で 本質的なのは閉写像に関する以下の現象である． この手の類の現象を初めて見出したのは [24] だと思われる． 論文 [16] も参照のこと．

定理 36.

XをT1正規位相空間とし， Yを第一可算な位相空間とする． そして写像f:X→Y は連続で閉写像であるとする． このとき 任意のy∈Y について Fr⁢f←⁢(y) は可算コンパクトである．

証明.

まず最初に f は全射であると仮定しても良い． そしてT1 であることは 閉写像によって保たれるので Yは T1 空間になる．

定理は背理法によって証明する． つまり， ある y∈Y について Fr⁢f←⁢(y) は可算コンパクトではないとする．

ここで Y は T1 なので f←⁢(y) は閉集合であり 特に Fr⁢f←⁢(y)⊂f←⁢(y) であることに注意しよう．

このとき 系 21 から Fr⁢f←⁢(y) の閉な可算離散部分空間 A={pi}i∈ℤ≥0 が存在する． 定理の仮定からYは第一可算なので yの可算な近傍系 {Vi}i∈ℤ≥0 が存在する． 定理 16 から疎な開集合の族 {Ui}i∈ℤ≥0 が存在して pi∈Ui となる． ここで f←⁢(y)⊂f←⁢(Vi) とf←⁢(Vi) が開集合であること， そして Fr⁢f←⁢(y)⊂f←⁢(y) を用いると， Ui∩f←⁢(Vi) はpiの開近傍であり 族 {Ui∩f←⁢(Vi)}i∈ℤ≥0 は疎な開集合からなる族である．

さてここで pi∈Fr⁢f←⁢(y) であることから， 各i∈ℤ≥0 について qi∈Ui∩f←⁢(Vi) であってなおかつ qi∉f←⁢(y) となるqi∈Xが存在する． 族{Ui} が疎であることから {{qi}}i∈ℤ≥0 も疎な族であり (補題14)， 集合B={qi∣i∈ℤ≥0} はXの閉集合である (補題10)． ここでB∩f←⁢(y)=∅ に注意しよう．

さて今f:X→Y は閉写像なので f⁢(B)も閉集合である． さらにB∩f←⁢(y)=∅ であることから y∉f⁢(B) なので y∈Y∖f⁢(B) である． 思い出して欲しいのだが {Vi}i∈ℤ≥0 はyの基本近傍系であり， なおかつ Y∖f⁢(B) は y を含む開集合なので y∈Vk⊂Y∖f⁢(B) となる k∈ℤ≥0 が存在する．

集合f⁢(B)は Yの閉集合であったから Y∖f⁢(B)は Yの開集合である． よってその引き戻し f←⁢(Y∖f⁢(B)) は X の開集合である． ここで帰属関係及び包含関係

y∈Vk⊂Y∖f⁢(B)

から

f←⁢(y)⊂f←⁢(Vk)⊂f←⁢(Y∖f⁢(B))

が従う． さてqkの定義から qk∈f←⁢(Vk) であるが これは qk∈f←⁢(Y∖f⁢(B)) を意味する． しかしこのことから f⁢(qk)∈Y∖f⁢(B) がわかるが， これは qk∈B に矛盾する．

以上の議論から 任意のy∈Y について Fr⁢f←⁢(y) は可算コンパクトである． ∎

距離化可能空間の閉像 が距離化可能になるために 必要十分条件 を述べた 以下の定理が 花井–森田・ストーンの定理である．

花井–森田による共著 [19] とストーンの論文 [23] が同時に 発表されているのでこの名前で呼ばれる．

定理 37 (Hanai–Morita, Stone).

Xを距離化可能空間とし， Yを位相空間とし f:X→Y は全射な連続閉写像であるとする． このとき以下は同値である．

  1. (1)

    Yは距離化可能である．

  2. (2)

    Yは第一可算である．

  3. (3)

    任意のy∈Y について Fr⁢f−1⁢(y) はコンパクトである．

証明.

(1) ⟹ (2) は自明である． そして定理 36 から (2) ⟹ (3) が従う．距離空間の部分集合について 可算コンパクトであることとコンパクトであることは同値であることに注意しよう． 以下では (3) ⟹ (1) を証明する．

写像 fは全射なので 各y∈Y について f←⁢(y) は空ではない． そこで適当に点 qy∈f←⁢(y) をとっておく． 各 y∈Y について X の開集合 Oy を 以下のように定義する．

Oy={INT⁢f←⁢(y)Fr⁢f←⁢(y)≠∅⁢のときf←⁢(y)∖{py}Fr⁢f←⁢(y)=∅⁢のとき

ここでFr⁢f←⁢(y)=∅のとき f←⁢(y)は開集合になっていることに注意しよう． 一般に境界が空な集合は開集合である(閉集合でもある，つまり開かつ閉である)． そして O=⋃y∈YOy として L=X∖O と定義する． このとき Lは Xの閉集合である． そして写像 g:L→Y を g=f|L と定義する． 集合Lは Xの閉部分集合であるから fが閉写像であることかた その制限であるg も閉写像になっている． しかも L の定義から 任意の y∈Yについて

g←⁢(y)={Fr⁢f←⁢(y)Fr⁢f←⁢(y)≠∅pyFr⁢f←⁢(y)=∅⁢のとき

が成り立つ． 写像 fに関する Fr⁢f←⁢(y) がコンパクトという 仮定より g←⁢(y)はコンパクトである． よって g は完全写像となる． つまり Yは完全写像gによる 距離化可能空間X の像なので， 定理 35 から Yも距離化可能である． これで証明が終わる． ∎

注意.

上の花井–森田・ストーンの定理 の以前に 論文 [4] で 花井 は距離化可能空間の閉像が 距離化可能であることを証明しているが， 証明に誤りが ある． 点y∈Yについて yを含む開集合Uに関して X∖f←⁢(U) を考えて，これと f←⁢(y)との距離をd としておりこれが正の数であることを用いて 証明をしているが， 一般にこのdは0になりうるのでここで証明が破綻している． ここで距離化可能空間の閉像が距離化可能ではない 例をあげよう． Xを単位閉区間[0,1] の無限個の位相的直和 とする．そしてそれぞれの成分の0 を一点に同一視した空間をY とする．ようはハリネズミ空間である． このとき商写像f:X→Y は閉写像となるが， Yは同一視された点において 第一可算性を満たさないので 特に距離化可能ではない． おそらくこの誤りを修正するのが 花井–森田の論文だろうと思われるので この閉像に関する間違いは 「発見的失敗」 と見なすことができるだろう．

以下の定理は [1] によるものらしい．

系 38.

Xを距離化可能空間とし， Yを位相空間とする． もしも全射で閉写像かつ開写像であるような 連続写像f:X→Y が存在するならば Yも距離化可能である．

証明.

このような状況において Y は第一可算であることがわかる． よって 定理 37 から Y が距離化可能であることがわかる． ∎

注意.

論文 [19] と 論文 [23] では 花井–森田・ストーンの定理 (定理 37) を証明する際に Alexandroff–Urysohn–Tukey のような被覆列を用いた距離化可能定理や， Frinkによる近傍系を用いた距離化可能定理 を用いている． 長田の論文 [21] ではのちにdouble sequence theorem などと呼ばれることになる 近傍系を用いた距離化可能定理から既存の 距離化可能定理を証明しており， その中の一つに 花井–森田・ストーンの定理 (定理 37) がある．

注意.

距離化可能定理については [12] や [2] も参照のこと．

8 完備距離化可能性

このセクションは説明不足である． 特にストーンチェックコンパクト化の話が説明不足である． 適当に参考文献で補ってほしい． このセクションでは 完備距離化可能性が完全写像で保たれる ことを証明する． これは 論文 [14] においてなんか知らんが Bing’s shrinkability criterion の話の延長 として証明されているようだ．

以下の事実は Willardの位相空間論の本 [25] のTheorem 24.13 である．

事実 39.

距離化可能空間 X が完備距離化可能であることと Xのストーンチェックコンパクト化 β⁢Xの中で X が Gδ であることが同値である．

以下の命題の証明は [3] のLemma 3.7.4 を参考にした．

命題 40.

位相空間X と Y は完全正則であるとし， 連続写像 f:X→Y は完全写像とする． このとき β⁢f⁢(β⁢X∖X)⊂β⁢Y∖Y が成り立つ． さらにfが全射ならば β⁢f⁢(β⁢X∖X)=β⁢Y∖Y が成り立つ．

証明.

前半を示そう． 背理法を行う． いま β⁢f⁢(β⁢X∖X)⊄β⁢Y∖Y と仮定する． すると ある z∈Y が存在して β⁢f←⁢(z) がβ⁢X∖X と交わりを持つ． その交わりから元 uを取ろう．

今から Z=X⊔{u} とおき そして g=β⁢f|Z とおく． すると fが完全写像 であり Zは Xに一点を付け加えただけなので g も完全写像になる． さらに g⁢(Z)⊂Y でもある．

また，Zの中で Xは稠密である． つまりZの中で Xの閉包をとると uを含む．

以上の状況のもとで g←⁢(z)=f←⁢(z)⊔{u} である． u∉Xなので 特に u∉f←⁢(z) である． よって f←⁢(z) のコンパクト性から Zの 開集合UとV であって u∈U， f←⁢(z)⊂V, そして U∩V=∅ を満たすものが存在する． ここでu∉V なのでVは Xの開集合でもある． さらに X∖V は X の閉集合である．

以上のことと f が閉写像であることから f⁢(X∖V) は Y の閉集合であり f←⁢(z)∩V=∅ であるから z∉f⁢(X∖V) である． ここで g は f の拡張であるから g←⁢(f⁢(X∖V)) は X∖V を含む Zの閉集合であり， z∉f⁢(X∖V) なので g←⁢(f⁢(X∖V))=f←⁢(f⁢(X∖V)) である． よって f←⁢(f⁢(X∖V))⊂X から CLZ⁢(X∖V)⊂X である．

ところで U∩V=∅ から u∉CLZ⁢(V) である．故に CLZ⁢(V)⊂X である． 以上のことから CLZ⁢(X∖V)∪CLZ⁢(V)⊂X である．

また X⊂(X∖V)∪V⊂CLZ⁢(X∖V)∪CLZ⁢(V) なので結局 X=CLZ⁢(X∖V)∪CLZ⁢(V) がわかる．

よって X は Z の閉集合となるが， これは u∉X という事実と， X が Z(=X⊔{u}) の中で稠密であるということに矛盾する． つまり β⁢f⁢(β⁢X∖X)⊂β⁢Y∖Y が成り立つ．

後半を示そう． 空間Y は β⁢Y の中で稠密である． 今fが全射つまり f⁢(X)=Y であるから β⁢f⁢(β⁢X) は稠密部分集合 Yを含むような β⁢Y の閉集合であるから (コンパクト空間からハウスドルフ空間への連続写像)， β⁢f⁢(β⁢X)=β⁢Y である． そして前半の 話から β⁢f⁢(β⁢X∖X)⊂β⁢Y∖Y である． もしもこれが真の包含だとすると β⁢f⁢(β⁢X)=β⁢Yに矛盾するので β⁢f⁢(β⁢X∖X)=β⁢Y∖Y が成り立つ． ∎

以下の定理に関しては 論文 [17] も参照のこと．

定理 41.

距離化可能空間 X は完備距離化可能とし， Yは位相空間で 連続写像 f:X→Y は完全写像とする． このとき Yも完備距離化可能である．

証明.

今から Y がβ⁢Yの中で Gδ であることを証明する． 事実 39 から Xは β⁢X の中でGδ である． つまり 可算個の β⁢Xの 開集合 {On}n∈ℤ≥0 が 存在して X=⋂n∈ℤ≥0On が成り立つ． さて β⁢f:β⁢X→β⁢Y はコンパクト空間からハウスドルフ空間への 連続写像なので特に閉写像である． よって任意の n∈ℤ≥0 について (β⁢f)?⁢(On) は β⁢Y の開集合になる (定理27)． ここで

⋂n∈ℤ≥0(β⁢f)?⁢(On) =(β⁢f)?⁢(⋂n∈ℤ≥0On)=(β⁢f)?⁢(X)=β⁢Y∖f⁢(β⁢X∖X)
=β⁢Y∖(β⁢Y∖Y)=Y

なので (一般に小像は⋂と可換になる，なぜなら順像は⋃と可換だからである)， 集合 Yは可算個の β⁢Yの開集合 {(β⁢f)?⁢(On)}n∈ℤ≥0 の共通部分でかける． 故に Yは β⁢Y のGδ 集合である． 再び事実 39 から Y が完備距離化可能であることがわかる． ∎

定理 42.

定理 37 と同じ記号を用いて同じ仮定をし， 定理 37で述べられている三つの条件 のいずれか一つ(結果として全て)が成り立つと仮定する． このときもしも Xが完備距離化可能ならば Yも完備距離化可能である．
